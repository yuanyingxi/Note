# 1. `final` 关键字

`final` 主要用于修饰类、方法和变量，核心作用是限制继承、重写和重新赋值。

## 1.1 `final` 修饰类

**作用：被** `final` **修饰的类不能被继承。**

```java
public final class Person {
}

// 编译错误：Person 不能被继承
// class Student extends Person {
// }
```

例如，Java 中的 `String` 类就是 `final` 类。

这样可以防止其他类通过继承修改该类原有的行为。

注意：`final` **类不一定是不可变类。** 如果类内部存在可以修改的成员变量或修改对象状态的方法，对象的内容仍然可能发生变化。

## 1.2 `final` 修饰方法

**作用：被** `final` **修饰的方法不能被子类重写（Override）。**

```java
class Parent {
    public final void show() {
        System.out.println("Parent");
    }
}

class Child extends Parent {
    // 编译错误：不能重写 Parent 的 final 方法
    // public void show() {
    //     System.out.println("Child");
    // }
}
```

注意：

- `final` 方法可以被子类继承和调用。
    
- `final` 方法不能被子类重写，但可以进行重载（Overload），即定义参数列表不同的同名方法。
    
- `Object` 类中的 `getClass()` 就是一个 `final` 方法。
    

## 1.3 `final` 修饰变量

**作用：变量只能完成一次赋值，赋值后不能再次改变其保存的值或引用。**

```java
final int num = 10;
// num = 20; // 编译错误：不能再次赋值
```

`final` 修饰的变量不一定要在声明时赋值，但必须在使用前完成赋值。

对于 `final` 实例变量，可以在**声明时、实例初始化块中或构造方法中**赋值，但必须保证构造完成时已经赋值，且不能重复赋值。

#### 基本类型和引用类型的区别

**（1）基本类型**

```java
final int num = 10;
// num = 20; // 不允许修改变量保存的值
```

基本类型变量保存的是具体的值，因此不能再次修改该值。

**（2）引用类型**

```java
final StringBuilder builder = new StringBuilder("Hello");

builder.append(" World"); // 可以修改对象内部的内容

// builder = new StringBuilder("Java");
// 编译错误：不能让 builder 指向另一个对象
```

**引用类型变量保存的是对象的引用。`final` 限制的是引用不能重新赋值，而不是对象内部的内容不能修改，所以 final 修饰的引用变量可以修改对象内部的内容。**

## 1.4 `final` 和常量的关系

`final` 变量不一定都是编译期常量。

例如：

```java
final int a = 10;          // 编译期常量
final int b = getValue();  // 运行时常量

static int getValue() {
    return 20;
}
```

- `a` 是编译期常量，因为它是基本类型，并通过常量表达式初始化。
    
- `b` 虽然被 `final` 修饰，但初始化值来自方法调用，不属于编译期常量。
    

对于基本类型和 `String` 类型，只有满足相应的常量表达式初始化条件，`final` 变量才属于 Java 语言定义的常量变量。

### 1.5 为什么 `String` 是不可变的？

`String` 的不可变性不只是因为它被 `final` 修饰。

主要原因包括：

1. `String` 类不能被继承，避免子类改变其行为。
    
2. 内部存储受到封装，不提供直接修改自身内容的公开方法。
    
3. 对内部数据的管理避免了可变存储被外部直接修改。
    

因此，设计不可变对象时，除了使用 `final`，还需要考虑字段的封装、可变成员的防御性拷贝等问题。

# 2. `static` 关键字

`static` 的核心作用是将成员与类本身关联，而不是与某个对象实例关联。

常见用途包括：

- 静态变量
    
- 静态方法
    
- 静态代码块
    
- 静态内部类
    

## 2.1 `static` 修饰变量

静态变量也叫类变量，属于类本身，**所有对象共享同一份静态变量**。

```java
public class Student {
    public static String schoolName = "第一中学";

    private String name;
}
```

这里：

- `schoolName` 是静态变量，所有 `Student` 对象共享同一个值。
    
- `name` 是实例变量，每个对象都有自己的值。
    

访问静态变量时，推荐使用类名：

```java
System.out.println(Student.schoolName);
```

例如，创建多个学生对象时，它们共享同一个 `schoolName`，但各自拥有独立的 `name`。

静态变量常用于存储类级别的共享数据，例如计数器、共享配置等。

## 2.2 `static` 修饰方法

静态方法属于类本身，不依赖于某个对象实例。

```java
public class MathUtils {
    public static int add(int a, int b) {
        return a + b;
    }
}
```

调用时不需要创建对象：

```java
int result = MathUtils.add(2, 3);
```

静态方法常用于工具方法、工厂方法等不依赖具体对象状态的场景。

#### 为什么静态方法不能直接访问非静态成员？

```java
public class Student {
    private String name = "Tom";

    public static void printName() {
        // System.out.println(name); // 编译错误
    }
}
```

原因是：

- 静态方法属于类，不需要创建对象就可以调用。
    
- 非静态成员属于具体对象，需要通过对象实例访问。
    
- **调用静态方法时，不一定存在可供使用的对象，因此无法直接确定应该访问哪个对象的 `name`。**
    

如果确实需要访问非静态成员，可以先获取一个对象引用，再通过该引用访问。

需要注意：静态方法可以直接访问同一个类中的静态成员。

#### 静态方法不能被重写吗？

静态方法不能按照普通实例方法的规则进行重写。

如果子类定义了一个与父类静态方法同名、参数列表相同的静态方法，这叫作**方法隐藏（Method Hiding）**，而不是重写。

## 2.3 `static` 修饰代码块

静态代码块用于执行类级别的初始化操作。

```java
public class DatabaseConfig {
    private static String url;

    static {
        url = "jdbc:mysql://localhost:3306/test";
        System.out.println("静态代码块执行");
    }
}
```

静态代码块的特点：

1. 在类的初始化阶段执行。
    
2. 对于同一个类加载器加载的同一个类，正常情况下只执行一次。
    
3. 多个静态代码块按照代码中的定义顺序执行。
    
4. 执行顺序早于该类对象的实例初始化过程和构造方法。
    

注意：静态代码块是在 JVM 的类初始化阶段执行的，不应简单地说成是在类加载阶段执行。

## 2.4 `static` 修饰内部类

Java 允许使用 `static` 修饰嵌套在另一个类中的类，称为**静态内部类（更准确地说是静态嵌套类）**。

```java
public class Outer {
    private static int staticNum = 10;
    private int instanceNum = 20;

    public static class Inner {
        public void print() {
            System.out.println(staticNum); // 可以直接访问

            // System.out.println(instanceNum);
            // 编译错误：不能直接访问外部类的实例成员
        }
    }
}
```

创建静态内部类的对象时，不需要先创建外部类对象：

```java
Outer.Inner inner = new Outer.Inner();
inner.print();
```

静态内部类的特点：

- 不依赖于外部类的对象实例，可以独立创建。
    
- 可以直接访问外部类的静态成员，包括私有静态成员。
    
- 访问外部类的非静态成员时，需要先获得外部类对象的引用。
    
- 不会像非静态内部类那样隐式持有外部类实例的引用。
    

注意：静态内部类并不是顶层类。Java 不允许直接使用 `static` 修饰普通的顶层类。

# 3. `final` 和 `static` 的区别

| 对比项    | `final`           | `static`         |
| ------ | ----------------- | ---------------- |
| 核心作用   | 限制继承、重写或重新赋值      | 将成员与类本身关联        |
| 修饰类    | 类不能被继承            | 不能直接修饰普通顶层类      |
| 修饰方法   | 方法不能被子类重写         | 方法属于类，不依赖对象实例    |
| 修饰变量   | 变量只能赋值一次          | 静态变量由同一个类的对象共享   |
| 能否组合使用 | 可以与 `static` 一起使用 | 可以与 `final` 一起使用 |

常见组合：

```java
public static final double PI = 3.1415926;
```

这里：

- `static`：变量属于类，所有对象共享。
    
- `final`：变量只能赋值一次。
    
- `public`：其他满足访问条件的代码可以访问该变量。
    

`static final` 常用于定义常量。

# 4. 面试重点总结

1. `final` **修饰类、方法、变量分别有什么作用？**
    
    - 类不能被继承。
        
    - 方法不能被子类重写。
        
    - 变量只能赋值一次。
        
2. `final` **引用的对象一定不可变吗？**
    
    - 不一定。引用不能重新赋值，但对象内部的内容仍可能修改。即 **`final` 修饰引用变量时，变量不能重新指向新对象，但原对象里面的属性可以变。**
        
3. **静态变量和实例变量有什么区别？**
    
    - 静态变量属于类，同一个类的对象共享。
        
    - 实例变量属于对象，每个对象分别持有自己的实例状态。
        
4. **为什么静态方法不能直接访问非静态成员？**
    
    - 静态方法不依赖对象实例，而非静态成员需要通过具体对象访问。
        
5. **静态方法能被重写吗？**
    
    - 不能按照实例方法的规则重写。子类定义同签名的静态方法属于方法隐藏。
        
6. **静态代码块什么时候执行？**
    
    - 在**类初始化阶段执**行；同一个类在同一个类加载器下正常情况下只初始化一次。
        
7. **静态内部类和非静态内部类有什么区别？**
    
    - 静态内部类不依赖外部类实例；非静态内部类需要关联外部类实例。
        
8. `final` 和 `static final` **有什么区别？**
    
    - `final` 只表示不能再次赋值；`static final` 表示类级别共享且不能再次赋值。`static final` 常用于定义常量，但并非所有 `static final` 变量都是编译期常量。
