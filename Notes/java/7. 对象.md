# 1. Java 创建对象有哪些方式？

Java 中常见的对象创建方式有以下几种。

## 1.1 使用 `new` 关键字

这是最常见、最直接的创建方式，通过调用构造方法创建对象。

```java
class Person {
    String name;

    public Person(String name) {
        this.name = name;
    }
}

Person person = new Person("小明");
```

执行 `new Person("小明")`，会创建一个 `Person` 对象，并调用对应的构造方法进行初始化。

## 1.2 使用反射创建对象

反射允许程序在运行时获取类的信息，并动态创建对象。

```java
Person person = Person.class
        .getDeclaredConstructor(String.class)
        .newInstance("小明");
```

这里通过反射获取 `Person` 的构造方法，再调用它创建对象。

**特点：**

- 可以在运行时动态决定创建哪个类的对象。
    
- 常用于 Spring 等框架，根据配置信息创建和管理对象。
    
- `Class.newInstance()` 已过时，推荐使用 `Constructor.newInstance()`。
    

## 1.3 使用 `clone()` 创建对象副本

`clone()` 可以根据已有对象创建一个新的对象副本。

```java
class Person implements Cloneable {
    String name;

    @Override
    public Person clone() throws CloneNotSupportedException {
        return (Person) super.clone();
    }
}
```

使用时：

```java
Person person1 = new Person();
person1.name = "小明";

Person person2 = person1.clone();
```

此时，`person2` 是新创建的对象，不是 `person1` 本身。

注意：

- 通常需要实现 `Cloneable` 接口，并调用或重写 `clone()` 方法。
    
- `Object.clone()` 默认执行浅拷贝。
    
- 浅拷贝会复制字段值；对于引用类型字段，复制的是引用值，而不是引用对象本身。
    

## 1.4 使用反序列化创建对象

反序列化可以从字节流中恢复对象。

```java
ObjectInputStream in = new ObjectInputStream(
        new FileInputStream("person.dat")
);

Person person = (Person) in.readObject();
in.close();
```

使用 Java 原生序列化时，相关类需要实现 `Serializable` 接口，并且输入流中的数据必须符合对应的序列化格式。

**特点：**

- 可以将保存到文件或通过网络传输的对象数据恢复为对象。
    
- 对于可序列化类，反序列化不会调用该类自身的构造方法，但会调用其第一个不可序列化父类的无参构造方法。
    
- 使用时需要处理文件、流及反序列化异常；不要反序列化不可信的数据。
    

## 1.5 使用工厂方法获取对象

工厂方法将对象的创建过程封装起来，使用者不必直接调用构造方法。

```java
class Person {
    private String name;

    private Person(String name) {
        this.name = name;
    }

    public static Person create(String name) {
        return new Person(name);
    }
}
```

使用时：

```java
Person person = Person.create("小明");
```

**优点：**

- 将对象创建与使用分离。
    
- 可以在创建过程中进行参数检查、缓存或其他处理。
    
- 可以隐藏具体的创建细节。
    

注意：工厂方法是一种设计方式，并不是独立的底层对象创建机制。工厂方法内部仍然可能使用 `new`、反射等方式创建对象，也可能直接返回已有对象。

## 1.6 几种方式的对比

|方式|核心原理|主要特点|
|---|---|---|
|`new`|调用构造方法|最常用、最直接|
|反射|运行时获取构造方法并调用|可以动态创建对象|
|`clone()`|复制已有对象|默认是浅拷贝|
|反序列化|从字节流恢复对象|常用于对象数据的存储与传输|
|工厂方法|封装对象的创建过程|降低调用方与具体创建方式的耦合|

# 2. Java 创建对象除了 `new` 还有哪些方式？

面试中，这个问题通常重点考查以下三种方式：

1. **反射**：运行时获取类或构造方法的信息，并通过构造方法创建对象。
    
2. **反序列化**：通过 `ObjectInputStream.readObject()` 从字节流中恢复对象。
    
3. `clone()`：根据已有对象创建一个副本，默认是浅拷贝。
    

工厂方法也经常被列入对象创建方式的讨论中，但它属于设计层面的封装方式，内部仍可能使用 `new` 等机制。

# 3. `new` 创建的对象什么时候被回收？

Java 的垃圾回收器（GC）负责自动回收不再使用的对象所占用的内存。

### 3.1 如何判断对象是否可以回收？

HotSpot JVM 主要通过**可达性分析**判断对象是否仍然存活。

**可达性分析就是从 GC Roots 出发，判断能否通过引用链找到对象。找不到的对象属于不可达对象，具备被 GC 回收的条件，但不保证立即回收。**

这些**起点**称为 **GC Roots**，常见的有：

- **线程栈中的局部变量**：例如方法中定义的变量 `Person person = new Person()`，如果 `person` 仍然引用该对象，那么该对象就可以从线程栈找到。
    
- **类的静态字段引用的对象**：例如 `static Person person = new Person()`，只要该静态字段仍然持有这个引用，并且对应的类加载器等仍然存活，该对象就可能从 GC Roots 被找到。
    
- **JNI 全局引用指向的对象**：Java 程序通过 JNI 与本地代码交互时，如果本地代码持有 JNI 全局引用，该引用指向的对象也需要保留。
    

**判断原则：** 如果一个对象仍然能够从 GC Roots 沿着引用关系找到，就不能仅仅因为其他变量不再引用它而回收；如果找不到，则可能被回收，但不代表会立即回收。
    

## 3.2 将变量设为 `null`，对象就会被回收吗？

不一定。

```java
Object obj = new Object();
Object other = obj;

obj = null;
```

此时，虽然 `obj` 不再引用该对象，但 `other` 仍然引用它，所以对象仍然可达。

继续执行：

```java
other = null;
```

假设没有其他可达引用，该对象就可能成为垃圾回收的候选对象。

**注意：对象失去引用不代表它会立即被回收。**

## 3.3 循环引用会导致对象无法回收吗？

不会仅仅因为循环引用就无法回收。

例如，A 引用 B，B 也引用 A。如果从 GC Roots 出发已经无法到达这两个对象，它们仍然可以被垃圾回收。

这说明 Java 的可达性分析并不是简单地统计对象被引用的次数。

## 3.4 对象什么时候真正被回收？

对象成为垃圾回收候选对象后，实际回收时间由 JVM 的垃圾回收时机和策略决定，并不保证立即发生。

即使调用：

```java
System.gc();
```

也只是向 JVM **提出进行垃圾回收的请求**，并不能保证立即执行垃圾回收。

## 3.5 GC 能否代替资源释放？

不能。

GC 主要负责回收**对象占用的内存**。文件、数据库连接、Socket 等外部资源应当及时释放，而不是等待 GC。

例如，使用 `try-with-resources`：

```java
try (FileInputStream in = new FileInputStream("data.txt")) {
    // 读取文件
}
```

代码离开 `try` 语句块后，资源会自动关闭。

另外，不要依赖 `finalize()` 释放资源。它的执行时机没有保证，并且从 Java 9 起已被弃用。

# 4. 如何获取私有字段的值？

`private` 用于限制成员的直接访问。通常有两种获取私有字段值的方式。

## 4.1 通过 getter 方法获取

这是常见、推荐的方式。

```java
class Person {
    private String name = "小明";

    public String getName() {
        return name;
    }
}
```

使用时：

```java
Person person = new Person();
String name = person.getName();
```

`name` 是私有字段，但类提供了公开的 `getName()` 方法，因此外部可以通过这个方法获取它的值。

## 4.2 通过反射获取

如果没有提供 getter 方法，可以通过反射读取私有字段。

```java
import java.lang.reflect.Field;

class Person {
    private String name = "小明";
}

Person person = new Person();

Field field = Person.class.getDeclaredField("name");
field.setAccessible(true);

String name = (String) field.get(person);
System.out.println(name); // 小明
```

主要步骤：

1. 获取类对应的 `Class` 对象。
    
2. 通过 `getDeclaredField()` 获取指定字段。
    
3. 通过 `setAccessible(true)` 尝试允许反射访问该字段。
    
4. 使用 `field.get(person)` 获取字段值。
    

注意：在现代 Java 中，模块访问限制等因素可能导致反射访问失败，因此 `setAccessible(true)` 并不保证任何情况下都能访问私有字段。

**使用原则：** 普通业务代码优先通过公开方法访问字段；反射通常用于框架、测试或其他需要动态处理类结构的场景。

# 5. 总结

1. Java 常见的对象创建方式包括 `new`、反射、`clone()`、反序列化和工厂方法。
    
2. `clone()` 默认执行浅拷贝；反射通常通过调用构造方法创建对象。
    
3. Java 主要通过可达性分析判断对象是否仍然存活。
    
4. 将变量设为 `null`，不代表对象立即被回收；循环引用的对象也可能被回收。
    
5. `System.gc()` 不能保证立即回收对象。
    
6. GC 不负责替代文件、数据库连接等外部资源的及时释放。
    
7. 获取私有字段的值，可以使用 getter 方法或反射，普通业务代码优先使用公开方法。
