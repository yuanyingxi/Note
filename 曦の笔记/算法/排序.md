# 1. 排序算法基础
## 1.1 什么是排序？

**排序（Sorting）** 是指按照某个关键字（Key）的大小或其他规则，将一组数据重新排列，使数据按照指定顺序排列。

排序主要分为两种：

|类型|英文|说明|
|---|---|---|
|升序排序|Ascending Order|从小到大排列|
|降序排序|Descending Order|从大到小排列|

## 1.2 稳定性（Stability）

**稳定性（Stability）** 是指：如果两个元素的关键字相同，那么排序之后，它们原来的相对位置是否保持不变。

例如，原始数据：

```text
(张三, 90)
(李四, 80)
(王五, 90)
```

按照成绩从小到大排序：

```text
(李四, 80)
(张三, 90)
(王五, 90)
```

张三仍然排在王五前面，两个成绩相同的元素保持原来的相对位置，因此该排序算法是**稳定的（Stable）**。

如果排序后变成：

```
(李四, 80)
(王五, 90)
(张三, 90)
```

两个相同元素改变了原来的相对位置，因此该排序算法是**不稳定的（Unstable）**。

**注意：**

- 稳定性关注的是关键字相同的元素。
    
- 稳定性是排序算法本身的性质。
    
- 稳定排序不代表排序速度更快。
    

## 1.3 时间复杂度（Time Complexity）

时间复杂度用于衡量排序算法执行时间随数据规模增长的变化趋势。

通常需要关注三种情况：

|类型|英文|含义|
|---|---|---|
|最好时间复杂度|Best-case Time Complexity|输入数据处于最有利情况时的时间复杂度|
|平均时间复杂度|Average-case Time Complexity|一般情况下的时间复杂度|
|最坏时间复杂度|Worst-case Time Complexity|输入数据处于最不利情况时的时间复杂度|

常见时间复杂度：

|时间复杂度|含义|
|---|---|
|O(1)|常数时间|
|O(log n)|对数时间|
|O(n)|线性时间|
|O(n log n)|线性对数时间|
|O(n²)|平方时间|

其中，n 表示待排序元素的数量。

## 1.4 空间复杂度（Space Complexity）

空间复杂度用于衡量算法执行过程中额外需要的存储空间。

通常讨论排序算法时，关注的是**辅助空间复杂度（Auxiliary Space Complexity）**，即排序过程中额外使用的空间，不包含原始输入数组。

例如：

- 直接在原数组中交换元素，辅助空间通常为 O(1)。
    
- 归并排序需要额外创建数组，辅助空间通常为 O(n)。
    

## 1.5 原地排序（In-place Sorting）

原地排序是指主要在原始数组上进行排序，只使用常数级别的额外空间。

例如：

- 冒泡排序
    
- 直接插入排序
    
- 简单选择排序
    
- 堆排序
    

注意：快速排序虽然通常在原数组上进行划分，但递归调用需要使用栈空间，因此其辅助空间复杂度并不是严格的 O(1)。

# 2. 排序算法的分类

按照排序过程中采用的基本思想，可以将常见排序算法分为以下几类：

## 2.1 插入排序（Insertion Sort）

核心思想：将未排序元素插入到已经有序的部分。

主要包括：

- 直接插入排序（Straight Insertion Sort）
    
- 折半插入排序（Binary Insertion Sort）
    
- 希尔排序（Shell Sort）
    

## 2.2 交换排序（Exchange Sort）

核心思想：通过比较元素之间的大小关系，并交换元素的位置，使数据逐渐有序。

主要包括：

- 冒泡排序（Bubble Sort）
    
- 快速排序（Quick Sort）
    

## 2.3 选择排序（Selection Sort）

核心思想：每次从未排序部分中选择最小或最大的元素，放到正确的位置。

主要包括：

- 简单选择排序（Simple Selection Sort）
    
- 堆排序（Heap Sort）
    

## 2.4 归并排序（Merge Sort）

核心思想：使用分治思想，将数据拆分成更小的部分，分别排序后再合并。

# 3. 插入排序（Insertion Sort）

插入排序的基本思想是：

**将待排序的数据分成有序部分和无序部分，每次从无序部分中取出一个元素，插入到有序部分的正确位置。**

## 3.1 直接插入排序（Straight Insertion Sort）
### （1）基本思想

直接插入排序是最基本的插入排序算法。

具体过程：

1. 将第一个元素视为已经有序。
    
2. 从第二个元素开始，依次取出未排序元素。
    
3. 将当前元素与前面已经有序的元素进行比较。
    
4. 将比当前元素大的元素向后移动。
    
5. 找到正确位置后，将当前元素插入进去。
    
6. 重复上述过程，直到所有元素有序。
    

### （2）排序过程

原始数组：

```text
[5, 3, 4, 1]
```

第一轮：第一个元素 5 默认有序。

```text
[5 | 3, 4, 1]
```

取出 3，与 5 比较，将 5 向后移动，再插入 3。

```text
[3, 5 | 4, 1]
```

第二轮：取出 4。

因为 4 小于 5、大于 3，因此插入到 3 和 5 之间。

```text
[3, 4, 5 | 1]
```

第三轮：取出 1。

因为 1 比前面的元素都小，将 3、4、5 依次向后移动。

```text
[1, 3, 4, 5]
```

最终完成排序。

### （3）核心操作

直接插入排序主要包含两个操作：

- 比较（Comparison）：比较当前待插入元素与有序部分中的元素。
    
- 移动（Shifting）：将有序部分中比当前元素大的元素向后移动，为当前元素腾出位置。
    

注意：直接插入排序不是简单地不断交换相邻元素，而是通过移动元素完成插入。

### （4）时间复杂度

|情况|时间复杂度|原因|
|---|---|---|
|最好情况|O(n)|原数组已经有序，只需要进行一次线性遍历|
|平均情况|O(n²)|平均需要进行多次比较和移动|
|最坏情况|O(n²)|原数组完全逆序，需要大量比较和移动|

### （5）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|稳定（Stable）|

为什么稳定？

因为插入时只将比当前元素大的元素向后移动，相等元素不会改变相对位置。

### （6）特点总结

- 实现简单，容易理解。
    
- 适合数据量较小的情况。
    
- 对于基本有序的数据，效率较高。
    
- 是一种稳定的排序算法。
    
- 最坏和平均时间复杂度为 O(n²)。
    

## 3.2 折半插入排序（Binary Insertion Sort）

### （1）基本思想

折半插入排序也叫二分插入排序，是直接插入排序的改进版本。

它主要优化的是**寻找插入位置的过程**。

- 直接插入排序：使用顺序查找（Sequential Search）。
    
- 折半插入排序：使用折半查找（Binary Search）。
    

具体过程：

1. 将数组分成有序部分和无序部分。
    
2. 从无序部分取出一个元素。
    
3. 使用二分查找，在有序部分中寻找正确的插入位置。
    
4. 将该位置之后的元素依次向后移动。
    
5. 将当前元素插入正确位置。
    
6. 重复上述过程。
    

### （2）排序过程

原始数组：

```
[2, 4, 6, 8 | 5]
```

前面的 `[2, 4, 6, 8]` 已经有序，现在需要插入 5。

第一步：使用二分查找，比较中间元素 6。

```
5 < 6
```

因此在左半部分继续查找。

第二步：比较 4。

```
5 > 4
```

因此插入位置在 4 和 6 之间。

第三步：将 6 和 8 向后移动，将 5 插入。

```
[2, 4, 5, 6, 8]
```

### （3）与直接插入排序的区别

|对比|直接插入排序|折半插入排序|
|---|---|---|
|插入位置查找方式|顺序查找|折半查找|
|查找时间|O(n)|O(log n)|
|元素移动|需要|需要|
|辅助空间|O(1)|O(1)|
|稳定性|稳定|稳定|

### （4）时间复杂度

|情况|时间复杂度|原因|
|---|---|---|
|最好情况|O(n log n)|每次插入都需要进行折半查找|
|平均情况|O(n²)|查找较快，但仍然需要移动元素|
|最坏情况|O(n²)|需要移动大量元素|

**重点：折半插入排序减少的是比较次数，并没有减少大量移动元素的操作。**

因此整体时间复杂度仍然可能达到 O(n²)。

### （5）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|稳定（Stable）|

注意：折半查找确定插入位置时，应将新元素插入已有相同元素的后面，才能保持稳定性。

### （6）特点总结

- 使用二分查找减少比较次数。
    
- 仍然需要移动元素。
    
- 平均和最坏时间复杂度仍然是 O(n²)。
    
- 是一种稳定的排序算法。
    

## 3.3 希尔排序（Shell Sort）

### （1）基本思想

希尔排序又称**缩小增量排序（Diminishing Increment Sort）**，是对直接插入排序的一种改进。

直接插入排序对于基本有序的数据效率较高，但对于大量无序的数据，可能需要移动很多次。

希尔排序通过设置间隔（Gap），将数组中的元素分成若干组，对每组分别进行插入排序。

然后逐渐缩小间隔，直到间隔为 1，最后进行一次直接插入排序。

核心思想：

**先让元素进行较大跨度的移动，使整个数组逐渐接近有序，最后通过直接插入排序完成整体排序。**

### （2）排序过程

原始数组：

```
[8, 5, 3, 7, 6, 2, 1, 4]
```

假设初始间隔：

```
Gap = 4
```

按照间隔 4 分组：

```
第一组：[8, 6]
第二组：[5, 2]
第三组：[3, 1]
第四组：[7, 4]
```

对每组进行插入排序：

```
第一组：[6, 8]
第二组：[2, 5]
第三组：[1, 3]
第四组：[4, 7]
```

数组调整为：

```
[6, 2, 1, 4, 8, 5, 3, 7]
```

接下来缩小间隔：

```
Gap = 2
```

继续分组并进行插入排序。

最后：

```
Gap = 1
```

此时整个数组成为一个组，进行一次直接插入排序，完成最终排序。

### （3）核心概念：增量（Gap）

增量（Gap）表示参与同一组排序的元素之间的距离。

例如：

```
Gap = 3
```

分组方式：

```
a[0]、a[3]、a[6]……
a[1]、a[4]、a[7]……
a[2]、a[5]、a[8]……
```

随着 Gap 不断缩小，分组数量减少，每组包含的元素逐渐增多。

最终 Gap = 1，相当于对整个数组执行直接插入排序。

### （4）时间复杂度

希尔排序的时间复杂度与**增量序列（Gap Sequence）**密切相关。

不同的增量序列会得到不同的时间复杂度，因此没有一个适用于所有实现的统一复杂度。

常见教材中的简化结论：

|情况|时间复杂度|
|---|---|
|最好情况|与增量序列有关|
|平均情况|部分教材估算为 O(n^1.3)，并非统一结论|
|最坏情况|常见简单增量序列下为 O(n²)|

### （5）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|不稳定（Unstable）|

为什么不稳定？

希尔排序允许相隔较远的元素直接交换或移动，这可能改变相同元素之间的相对顺序。

### （6）特点总结

- 是直接插入排序的改进算法。
    
- 通过增量分组进行插入排序。
    
- 增量逐渐缩小，最后 Gap 为 1。
    
- 不稳定排序。
    
- 时间复杂度取决于增量序列。
    

# 4. 交换排序（Exchange Sort）

交换排序的核心思想是：

**通过比较元素之间的大小关系，并交换位置，使整个数组逐渐达到有序状态。**

主要包括：

- 冒泡排序（Bubble Sort）
    
- 快速排序（Quick Sort）
    

## 4.1 冒泡排序（Bubble Sort）

### （1）基本思想

冒泡排序是一种最简单的交换排序算法。

它通过比较相邻两个元素的大小，如果顺序不符合要求，就交换它们的位置。

每一轮排序结束后，当前未排序部分中的最大元素会移动到最后面。

### （2）排序过程

原始数组：

```
[5, 3, 8, 2, 1]
```

按照从小到大排序。

第一轮：

比较相邻元素，如果前面的元素大于后面的元素，就交换。

```
[5, 3, 8, 2, 1]
[3, 5, 8, 2, 1]
[3, 5, 8, 2, 1]
[3, 5, 2, 8, 1]
[3, 5, 2, 1, 8]
```

第一轮结束，最大元素 8 已经到达最后面。

第二轮：

不再比较最后面的 8。

```
[3, 5, 2, 1 | 8]
```

经过一轮比较和交换：

```
[3, 2, 1, 5 | 8]
```

第二轮结束，第二大的元素 5 也到达正确位置。

第三轮：

```
[2, 1, 3 | 5, 8]
```

第四轮：

```
[1, 2, 3, 5, 8]
```

最终完成排序。

### （3）优化：提前结束（Early Termination）

如果某一轮排序过程中，没有发生任何交换，说明整个数组已经有序。

此时不需要继续执行后续轮次，可以直接结束排序。

例如：

```
[1, 2, 3, 4, 5]
```

第一轮比较过程中没有发生交换，说明数组已经有序。

### （4）时间复杂度

|情况|时间复杂度|原因|
|---|---|---|
|最好情况|O(n)|数组已经有序，第一轮比较后直接结束|
|平均情况|O(n²)|通常需要多轮比较和交换|
|最坏情况|O(n²)|数组完全逆序，需要大量比较和交换|

注意：最好情况为 O(n) 的前提是使用了提前结束的优化版本。

### （5）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|稳定（Stable）|

为什么稳定？

冒泡排序只在前面的元素严格大于后面的元素时才交换。

相等的元素不会因为相邻比较而交换位置。

### （6）特点总结

- 通过比较相邻元素进行排序。
    
- 每一轮将当前最大元素放到未排序部分的末尾。
    
- 可以通过提前结束优化算法。
    
- 稳定排序。
    
- 平均和最坏时间复杂度均为 O(n²)。
    

## 4.2 快速排序（Quick Sort）

### （1）基本思想

快速排序是一种经典的交换排序算法，也是非常重要的分治算法（Divide and Conquer）。

核心思想：

**每次选择一个基准元素（Pivot），通过一轮划分，将数组分成左右两个部分，使左边元素不大于基准元素，右边元素不小于基准元素，然后递归处理左右两个部分。**

主要包含三个过程：

1. 选择基准元素（Pivot）。
    
2. 划分（Partition）。
    
3. 递归排序（Recursion）。
    

### （2）排序过程

原始数组：

```
[6, 3, 8, 2, 5, 1, 7]
```

选择第一个元素 6 作为基准元素：

```
Pivot = 6
```

通过划分操作，将数组调整为：

```
[3, 2, 5, 1]  6  [8, 7]
```

此时：

- 左边元素都不大于 6。
    
- 右边元素都不小于 6。
    
- 基准元素 6 已经位于最终位置。
    

接下来分别对左右两部分递归执行快速排序。

最终：

```
[1, 2, 3, 5, 6, 7, 8]
```

### （3）分治思想（Divide and Conquer）

分治通常包含三个过程：

|过程|英文|含义|
|---|---|---|
|分解|Divide|将原问题划分为较小的子问题|
|解决|Conquer|递归解决子问题|
|合并|Combine|将子问题的结果组合起来|

快速排序有一个特点：

**它主要通过划分操作完成排序，划分完成后不需要额外的合并操作。**

### （4）时间复杂度

|情况|时间复杂度|原因|
|---|---|---|
|最好情况|O(n log n)|每次划分都比较均匀|
|平均情况|O(n log n)|大多数情况下划分相对均衡|
|最坏情况|O(n²)|每次划分都极不均衡|

为什么最坏情况是 O(n²)？

假设数组已经有序，而且每次都选择第一个元素作为基准元素。

每次划分可能得到：

```
1 个元素 + n-1 个元素
```

递归过程：

```
T(n) = T(n-1) + O(n)
```

最终得到 O(n²)。

### （5）空间复杂度

快速排序通常使用递归实现，因此需要考虑递归调用栈（Recursion Stack）的空间。

|情况|空间复杂度|
|---|---|
|平均情况|O(log n)|
|最坏情况|O(n)|

原因：

- 平均情况下，递归深度约为 log n。
    
- 最坏情况下，递归深度可能达到 n。
    

### （6）稳定性

快速排序是不稳定排序（Unstable Sort）。

原因是划分过程中可能交换两个距离较远的元素，从而改变相同元素之间的相对位置。

### （7）特点总结

- 属于交换排序。
    
- 使用分治思想。
    
- 选择基准元素进行划分。
    
- 平均时间复杂度为 O(n log n)。
    
- 最坏时间复杂度为 O(n²)。
    
- 平均辅助空间复杂度为 O(log n)。
    
- 不稳定排序。
    
- 通常具有较高的实际运行效率。
    

# 5. 选择排序（Selection Sort）

选择排序的核心思想是：

**每一轮从未排序部分中选择一个最小或最大的元素，将它放到正确的位置。**

主要包括：

- 简单选择排序（Simple Selection Sort）
    
- 堆排序（Heap Sort）
    

## 5.1 简单选择排序（Simple Selection Sort）

### （1）基本思想

简单选择排序又称直接选择排序（Straight Selection Sort）。

具体过程：

1. 在未排序部分中找到最小的元素。
    
2. 将它与未排序部分的第一个元素交换。
    
3. 此时第一个元素已经处于正确位置。
    
4. 接下来在剩余未排序部分中继续寻找最小元素。
    
5. 重复上述过程，直到整个数组有序。
    

### （2）排序过程

原始数组：

```
[5, 3, 8, 2, 1]
```

第一轮：

在整个数组中寻找最小元素 1。

将 1 与第一个元素 5 交换：

```
[1, 3, 8, 2, 5]
```

第二轮：

第一个元素已经有序，在剩余部分寻找最小元素 2。

将 2 与当前未排序部分的第一个元素 3 交换：

```
[1, 2, 8, 3, 5]
```

第三轮：

找到最小元素 3，与 8 交换：

```
[1, 2, 3, 8, 5]
```

第四轮：

找到最小元素 5，与 8 交换：

```
[1, 2, 3, 5, 8]
```

最终完成排序。

### （3）与冒泡排序的区别

冒泡排序：

```
比较相邻元素 → 交换 → 比较相邻元素 → 交换
```

简单选择排序：

```
遍历未排序部分 → 找到最小元素 → 交换一次
```

冒泡排序通过相邻交换逐步移动最大元素，而简单选择排序是先找到最小元素，再进行交换。

### （4）时间复杂度

|情况|时间复杂度|原因|
|---|---|---|
|最好情况|O(n²)|即使数组已经有序，仍然需要遍历未排序部分|
|平均情况|O(n²)|需要多轮寻找最小元素|
|最坏情况|O(n²)|仍然需要大量比较|

注意：

即使原数组已经有序，简单选择排序也需要寻找每一轮未排序部分中的最小元素，因此最好时间复杂度仍然是 O(n²)。

### （5）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|不稳定（Unstable）|

为什么不稳定？

因为简单选择排序可能交换距离较远的元素。

例如：

```
[5a, 5b, 1]
```

找到最小元素 1，将它与第一个元素 5a 交换：

```
[1, 5b, 5a]
```

两个相同元素 5a 和 5b 的相对位置发生改变。

### （6）特点总结

- 每一轮选择未排序部分中的最小元素。
    
- 每一轮最多进行一次交换。
    
- 最好、平均和最坏时间复杂度都是 O(n²)。
    
- 辅助空间复杂度为 O(1)。
    
- 不稳定排序。
    

## 5.2 堆排序（Heap Sort）

### （1）基本思想

堆排序是一种基于堆（Heap）这种数据结构实现的选择排序算法。

**堆是一种特殊的完全二叉树（Complete Binary Tree）。**

堆主要分为两种：

|类型|英文|特点|
|---|---|---|
|大顶堆|Max Heap|每个父节点的值都大于或等于其子节点|
|小顶堆|Min Heap|每个父节点的值都小于或等于其子节点|

大顶堆示例：

```
          9
        /   \
       7     8
      / \   /
     3   2 5
```

特点：

```
父节点 ≥ 左子节点
父节点 ≥ 右子节点
```

因此，大顶堆的根节点一定是整个堆中的最大元素。

小顶堆示例：

```
          1
        /   \
       3     2
      / \   /
     8   5 6
```

特点：

```
父节点 ≤ 左子节点
父节点 ≤ 右子节点
```

因此，小顶堆的根节点一定是整个堆中的最小元素。

### （2）堆排序的基本过程

如果需要按照从小到大的顺序排序，通常使用**大顶堆（Max Heap）**。

基本步骤：

1. 将原始数组构建成一个大顶堆。
    
2. 此时堆顶元素就是整个堆中的最大元素。
    
3. 将堆顶元素与当前堆的最后一个元素交换。
    
4. 将最后一个元素移出当前堆的范围，它已经处于最终位置。
    
5. 对剩余元素重新进行调整，使其继续满足大顶堆的性质。
    
6. 重复上述过程，直到所有元素有序。
    

### （3）排序过程

原始数据：

```
[4, 6, 8, 5, 2]
```

第一步：建立大顶堆。

```
[8, 6, 4, 5, 2]
```

对应的堆结构：

```
          8
        /   \
       6     4
      / \
     5   2
```

第二步：交换堆顶元素和最后一个元素。

```
[2, 6, 4, 5 | 8]
```

最大元素 8 已经处于最终位置。

第三步：重新调整剩余部分。

```
[6, 5, 4, 2 | 8]
```

第四步：继续交换和调整。

```
[2, 5, 4 | 6, 8]
```

重新调整：

```
[5, 2, 4 | 6, 8]
```

然后继续：

```
[4, 2 | 5, 6, 8]
```

最终：

```
[2, 4, 5, 6, 8]
```

### （4）重要概念：堆调整（Heapify）

堆调整（Heapify）是堆排序中的重要操作。

作用：

**调整某个节点及其子树，使其重新满足大顶堆或小顶堆的性质。**

例如，大顶堆中，某个节点比它的子节点小，就需要将它与较大的子节点交换，然后继续向下调整。

需要掌握：

- 构建大顶堆（Build Max Heap）。
    
- 堆调整（Heapify）。
    
- 堆顶元素（Root）。
    
- 完全二叉树（Complete Binary Tree）。
    

### （5）数组表示堆

堆通常可以使用数组进行存储。

对于下标从 0 开始的数组，假设某个节点的下标为 i：

|节点|下标|
|---|---|
|父节点|(i - 1) // 2|
|左孩子|2 * i + 1|
|右孩子|2 * i + 2|

例如：

```
数组：[8, 6, 4, 5, 2]

          8 (0)
        /       \
      6 (1)     4 (2)
      / \
   5 (3) 2 (4)
```

### （6）时间复杂度

|情况|时间复杂度|
|---|---|
|最好情况|O(n log n)|
|平均情况|O(n log n)|
|最坏情况|O(n log n)|

堆排序主要包含两个过程：

① 建立初始堆：

```
O(n)
```

② 反复取出堆顶元素：

每次取出最大元素后，需要重新调整堆，调整一次的时间复杂度为：

```
O(log n)
```

总共需要进行约 n 次调整，因此整体时间复杂度为：

```
O(n log n)
```

注意：建立堆的时间复杂度是 O(n)，而不是 O(n log n)。

### （7）空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(1)|
|稳定性|不稳定（Unstable）|

这里的 O(1) 按照常见的迭代式堆调整实现计算。

为什么不稳定？

因为堆排序过程中，堆顶元素需要与堆尾元素交换，可能改变相同元素之间的相对位置。

### （8）特点总结

- 基于完全二叉树实现。
    
- 大顶堆的根节点是最大元素。
    
- 小顶堆的根节点是最小元素。
    
- 使用大顶堆可以实现升序排序。
    
- 使用小顶堆可以实现降序排序。
    
- 时间复杂度最好、平均、最坏都是 O(n log n)。
    
- 辅助空间复杂度为 O(1)。
    
- 不稳定排序。
    

# 6. 归并排序（Merge Sort）

## 6.1 基本思想

归并排序是一种典型的分治算法（Divide and Conquer）。

核心思想：

**先将数组不断拆分成更小的部分，直到每个部分只剩下一个元素，然后将这些有序部分逐步合并，最终得到完整的有序数组。**

归并排序主要分为两个过程：

1. 拆分（Split）。
    
2. 合并（Merge）。
    

其中，合并是归并排序最重要的操作。

## 6.2 排序过程

原始数组：

```
[8, 4, 5, 7, 1, 3, 6, 2]
```

### 第一步：不断拆分

先将数组分成左右两个部分：

```
[8, 4, 5, 7]    [1, 3, 6, 2]
```

继续拆分：

```
[8, 4] [5, 7]    [1, 3] [6, 2]
```

继续拆分：

```
[8] [4] [5] [7] [1] [3] [6] [2]
```

直到每个部分只剩下一个元素。

### 第二步：合并

将相邻的单个元素进行合并，并按照从小到大的顺序排列。

```
[8] [4] → [4, 8]

[5] [7] → [5, 7]

[1] [3] → [1, 3]

[6] [2] → [2, 6]
```

继续合并：

```
[4, 8] [5, 7]
      ↓
[4, 5, 7, 8]
```

```
[1, 3] [2, 6]
      ↓
[1, 2, 3, 6]
```

最后合并两个较大的有序部分：

```
[4, 5, 7, 8] [1, 2, 3, 6]
```

得到：

```
[1, 2, 3, 4, 5, 6, 7, 8]
```

最终完成排序。

## 6.3 核心操作：合并（Merge）

归并排序最重要的过程就是将两个已经有序的数组合并成一个新的有序数组。

例如：

```
A = [2, 5, 8]
B = [1, 4, 6]
```

比较两个数组当前尚未处理的第一个元素：

第一步：

比较 2 和 1，选择较小的 1。

```
结果：[1]
```

第二步：

比较 2 和 4，选择较小的 2。

```
结果：[1, 2]
```

第三步：

比较 5 和 4，选择较小的 4。

```
结果：[1, 2, 4]
```

继续比较，最终得到：

```
[1, 2, 4, 5, 6, 8]
```

注意：

**归并操作要求参与合并的两个部分本身已经有序。**

## 6.4 时间复杂度

|情况|时间复杂度|
|---|---|
|最好情况|O(n log n)|
|平均情况|O(n log n)|
|最坏情况|O(n log n)|

为什么归并排序的时间复杂度是 O(n log n)？

① 拆分层数：

每次将数组拆分成两部分，数组规模每次减半。

因此拆分层数约为：

```
log₂ n
```

② 每一层合并的工作量：

每一层都需要处理全部 n 个元素，因此每一层的合并总工作量为：

```
O(n)
```

因此：

```
O(n) × O(log n) = O(n log n)
```

## 6.5 空间复杂度与稳定性

|指标|结果|
|---|---|
|辅助空间复杂度|O(n)|
|稳定性|稳定（Stable）|

为什么需要 O(n) 的辅助空间？

因为在合并两个有序数组时，通常需要额外创建临时数组（Temporary Array），用于保存合并后的结果。

为什么稳定？

因为在合并时，如果左右两部分当前元素相等，可以优先选择左边的元素。

这样就能保持相同元素之间的原始相对顺序。

## 6.6 特点总结

- 是典型的分治算法。
    
- 先拆分，再合并。
    
- 需要两个已经有序的部分才能进行归并。
    
- 最好、平均和最坏时间复杂度都是 O(n log n)。
    
- 辅助空间复杂度为 O(n)。
    
- 稳定排序。
    
- 适合处理较大规模的数据。
    

# 7. 八种常见排序算法对比

## 7.1 时间复杂度、空间复杂度和稳定性

|排序类别|排序算法|最好时间复杂度|平均时间复杂度|最坏时间复杂度|辅助空间复杂度|稳定性|
|---|---|---|---|---|---|---|
|插入排序|直接插入排序|O(n)|O(n²)|O(n²)|O(1)|稳定|
|插入排序|折半插入排序|O(n log n)|O(n²)|O(n²)|O(1)|稳定|
|插入排序|希尔排序|依赖增量序列|依赖增量序列|依赖增量序列|O(1)|不稳定|
|交换排序|冒泡排序|O(n)|O(n²)|O(n²)|O(1)|稳定|
|交换排序|快速排序|O(n log n)|O(n log n)|O(n²)|平均 O(log n)，最坏 O(n)|不稳定|
|选择排序|简单选择排序|O(n²)|O(n²)|O(n²)|O(1)|不稳定|
|选择排序|堆排序|O(n log n)|O(n log n)|O(n log n)|O(1)|不稳定|
|归并排序|归并排序|O(n log n)|O(n log n)|O(n log n)|O(n)|稳定|

**注意：**

1. 折半插入排序使用二分查找减少比较次数，但元素移动仍然可能需要 O(n²)。
    
2. 希尔排序的复杂度与增量序列有关，不存在适用于所有增量序列的统一复杂度。
    
3. 快速排序的空间复杂度需要考虑递归栈，平均为 O(log n)，最坏为 O(n)。
    
4. 冒泡排序最好情况为 O(n)，前提是使用提前结束优化。
    
5. 堆排序的 O(1) 辅助空间按照常见的迭代式堆调整实现计算。
    

## 7.2 稳定性总结

### 稳定排序（Stable Sort）

- 直接插入排序
    
- 折半插入排序
    
- 冒泡排序
    
- 归并排序
    

### 不稳定排序（Unstable Sort）

- 希尔排序
    
- 快速排序
    
- 简单选择排序
    
- 堆排序
    

**记忆方法：**

稳定的四种：

```
直接插入、折半插入、冒泡、归并
```

其余四种不稳定：

```
希尔、快速、简单选择、堆
```

## 7.3 各种排序算法的核心思想对比

|排序算法|核心思想|关键词|
|---|---|---|
|直接插入排序|将元素插入前面已经有序的部分|插入|
|折半插入排序|使用二分查找确定插入位置|二分查找|
|希尔排序|按增量分组，对各组进行插入排序|缩小增量|
|冒泡排序|比较相邻元素，满足条件时交换|相邻交换|
|快速排序|选择基准元素，划分左右部分|基准、分治|
|简单选择排序|从未排序部分选择最小元素|选择最小值|
|堆排序|利用堆顶元素最大或最小的特点排序|大顶堆、小顶堆|
|归并排序|不断拆分，再将有序部分合并|分治、合并|

# 8. 排序算法常见考点总结

## 8.1 哪些排序算法的时间复杂度是 O(n²)？

常见的平方级排序算法：

- 直接插入排序：平均、最坏 O(n²)。
    
- 折半插入排序：平均、最坏 O(n²)。
    
- 希尔排序：部分增量序列下最坏 O(n²)。
    
- 冒泡排序：平均、最坏 O(n²)。
    
- 简单选择排序：最好、平均、最坏均为 O(n²)。
    
- 快速排序：最坏 O(n²)。
    

## 8.2 哪些排序算法的时间复杂度是 O(n log n)？

- 快速排序：最好、平均 O(n log n)。
    
- 堆排序：最好、平均、最坏 O(n log n)。
    
- 归并排序：最好、平均、最坏 O(n log n)。
    

## 8.3 哪些排序算法的空间复杂度是 O(1)？

按照常见的迭代式原地排序实现：

- 直接插入排序
    
- 折半插入排序
    
- 希尔排序
    
- 冒泡排序
    
- 简单选择排序
    
- 堆排序
    

注意：

- 快速排序通常需要递归栈空间。
    
- 归并排序通常需要额外数组。
    

## 8.4 哪些排序算法适合处理基本有序的数据？

**直接插入排序和优化后的冒泡排序。**

原因：

- 直接插入排序在数据基本有序时，需要移动的元素较少。
    
- 冒泡排序在数据已经有序时，可以通过提前结束机制减少不必要的比较。
    

## 8.5 哪些排序算法采用分治思想？

主要包括：

- 快速排序（Quick Sort）
    
- 归并排序（Merge Sort）
    

二者的区别：

| 对比      | 快速排序          | 归并排序                    |     |
| ------- | ------------- | ----------------------- | --- |
| 核心思想    | 分区（Partition） | 分割和合并（Divide and Merge） |     |
| 主要操作    | 选择基准，划分左右部分   | 拆分数组，再合并有序部分            |     |
| 最好时间复杂度 | O(n log n)    | O(n log n)              |     |
| 平均时间复杂度 | O(n log n)    | O(n log n)              |     |
| 最坏时间复杂度 | O(n²)         | O(n log n)              |     |
| 辅助空间复杂度 | 平均 O(log n)   | O(n)                    |     |
| 稳定性     | 不稳定           | 稳定                      |     |

## 8.6 哪些排序算法每一轮选择最大或最小元素？

|算法|每一轮主要操作|
|---|---|
|冒泡排序|将当前未排序部分的最大元素移动到末尾|
|简单选择排序|找到当前未排序部分的最小元素，放到最前面|
|堆排序|取出堆顶最大元素，放到末尾|
