# 10. 题干高频动作词与句式（读题时最容易卡的地方）

| English | 中文 | 出现场景 |
| --- | --- | --- |
| Which of the following … | 下列哪个…… | 几乎所有选择题的开头 |
| … is correct / is NOT correct | ……是正确的 / 不正确的 | 判断题（注意 NOT） |
| Which of the following best describes … | 下列哪项最准确地描述了…… | 概念题 |
| NOT possible / CANNOT | 不可能 / 不能 | 出栈序列、SQL 题 |
| must / always / never | 必须 / 总是 / 从不 | 绝对化表述，通常是错项 |
| at least / at most / exactly | 至少 / 至多 / 恰好 | 计数题 |
| greater than / less than | 大于 / 小于 | 注意是否含等号 |
| inclusive / exclusive | 含端点 / 不含端点 | 区间、循环边界 |
| with respect to n | 关于 n（的复杂度） | 复杂度题 |
| how many times | 多少次 | 调用次数题 |
| in total (including …) | 总共（含……） | 调用次数题（别漏根调用） |
| Given | 已知、给定 | 条件题 |
| Assume / Suppose | 假设 | 条件题 |
| Determine | 判断、确定 | 代码题 |
| Calculate / Compute | 计算 | 计算题 |
| Derive | 推导 | 证明类 |
| Evaluate | 求值 | 极限、积分、表达式 |
| Estimate | 估计 | — |
| Implement | 实现 | 编程题 |
| Output | 输出 | 读代码题 |
| The value of … is | ……的值是 | 读代码题 |
| Defective | 有缺陷的 | 概率题 |
| Seated in a row | 坐成一排 | 排列题 |
| Distinct | 互不相同 | 排列题（是否可重复） |
| Adjacent | 相邻的 | 插空法 |
| Uniformly at random | 等概率随机 | 概率题 |
