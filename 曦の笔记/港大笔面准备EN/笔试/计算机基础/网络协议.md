# 1. 网络分层与常见协议

**题目方向：** 下列哪个协议能在不可靠的网络之上提供可靠、按序的字节流传输？

**知识点：Network Protocols**

（1）一张分层表（所有网络选择题都在这张表里找答案）

| 层                   | 协议                               | 职责           | 可靠？            |
| ------------------- | -------------------------------- | ------------ | -------------- |
| **应用层** Application | HTTP / HTTPS、DNS、FTP、SMTP        | 面向具体应用的数据交换  | 取决于下层          |
| **传输层** Transport   | **TCP**、**UDP**                  | 端到端（进程到进程）传输 | TCP 可靠、UDP 不可靠 |
| **网络层** Network     | **IP**、ICMP、路由协议（OSPF/BGP）、ARP\* | 逐跳转发、寻址      | **不可靠**（尽力而为）  |
| **链路层** Link        | Ethernet、Wi-Fi                   | 相邻结点间的帧传输    | 局部校验           |

ARP 的归属各教材不一：国内 408 教材多放在**网络层**，也有教材放在链路层。考试只需知道它是「IP → MAC 的地址解析」。

（2）五个协议各干什么

|协议|一句话职责|关键英文词|
|---|---|---|
|**TCP**|在不可靠网络上提供**可靠、按序的字节流**|connection-oriented, reliable, in-order, byte stream, ACK, retransmission|
|**UDP**|无连接、不保证送达与顺序，**开销小、时延低**|connectionless, best-effort, datagram|
|IP|逐跳转发数据包，**本身不可靠**|best-effort delivery, routing|
|ARP|**IP 地址 → MAC 地址**的解析|address resolution|
|ICMP|差错报告与探测（**ping** 的底层）|error reporting, echo request/reply|

（3）TCP 靠什么做到「可靠 + 按序」

|机制|解决什么|
|---|---|
|**序号 + 确认（ACK）**|知道哪些字节到了、哪些没到|
|**超时重传**|丢了就再发|
|**三次握手 / 四次挥手**|建立与释放连接（同步初始序号）|
|**滑动窗口 + 流量控制**|别把接收方灌爆（接收方能力）|
|**拥塞控制**（慢启动、拥塞避免）|别把网络灌爆（网络状况）|
|**按序号重组**|乱序到达也能拼回原顺序|

一句话：**流量控制看接收方，拥塞控制看网络。**

（4）什么时候用 UDP

**实时音视频、在线游戏、DNS 查询、直播**——宁可丢一帧也不要等重传（等到了也过期了）。「可靠」不是免费的：重传与拥塞控制会带来延迟抖动。

（5）题干关键词 → 答案（比背协议栈更快）

| 题干说                                                  | 答案       |
| ---------------------------------------------------- | -------- |
| reliable, in-order, byte stream, connection-oriented | **TCP**  |
| connectionless, low latency, best-effort, datagram   | **UDP**  |
| resolves IP to MAC                                   | **ARP**  |
| ping / error reporting                               | **ICMP** |
| best-effort packet forwarding, routing               | **IP**   |
| application-level, request-response, stateless       | **HTTP** |

**所属知识点：** 计算机基础 / 计算机网络 / 协议分层。

# 2. 英文例题

Which protocol provides **reliable, in-order** delivery of a **byte stream** over an unreliable network?

A. UDP

B. IP

C. TCP

D. ARP

E. ICMP

**答案：C**

**解析：** 题干三个关键词 `reliable`、`in-order`、`byte stream` 每一个都指向 TCP。UDP 不保证送达与顺序；IP 只做尽力而为的转发；ARP 做地址解析；ICMP 做差错报告。

**所属知识点：** 计算机基础 / 计算机网络 / 传输层协议。
