# 1. 进程与线程

**题目方向：** 关于进程与线程，下列说法正确的是？（选项涉及地址空间、共享资源、切换开销、进程内的线程数）

**知识点：Process vs Thread**

（1）一句话定位

> **进程（process）是资源分配的基本单位；线程（thread）是 CPU 调度的基本单位。**

一个进程 = 一块独立的**地址空间** + 若干线程；同一进程内的线程**共享**这块地址空间。

（2）共享什么、私有什么（本题唯一考点）

|资源|同进程的线程之间|不同进程之间|
|---|---|---|
|地址空间（代码段、数据段）|✅ **共享**|❌ 隔离|
|堆 Heap（new / malloc 出来的）|✅ **共享**|❌ 隔离|
|全局变量 / 静态变量|✅ 共享|❌ 隔离|
|打开的文件描述符|✅ 共享|❌ 各自一份|
|**栈 Stack**|❌ **每线程私有**|❌ 私有|
|**寄存器 / 程序计数器 PC**|❌ **每线程私有**|❌ 私有|
|线程局部存储 TLS|❌ 私有|—|

记忆钩子：**「堆共享、栈私有」。** 堆是「进程的资源」，栈是「一条执行流的现场」——每个线程在跑不同的函数，现场当然不能共用。

（3）这直接解释了两个现象

- 多线程同时写同一个全局变量会出**竞态条件（race condition）**，因为它们共享堆和全局区；
- 每个线程的**局部变量**不会冲突，因为栈是私有的。

（4）切换开销：进程切换 > 线程切换

|切换类型|要做什么|开销|
|---|---|---|
|线程切换（同进程内）|保存/恢复寄存器、栈指针、PC；**地址空间不变**|小|
|进程切换|上面全部 **＋ 换页表、刷新 TLB**|**大**|

换页表之所以贵：切换进程后虚拟地址到物理地址的映射整套换掉，TLB 里缓存的映射全部失效，之后每次访存都要重新走页表。

（5）隔离性带来的差别

| |进程|线程|
|---|---|---|
|崩溃影响|通常不影响其他进程|**可能拖垮整个进程**（共享地址空间）|
|通信方式|管道、消息队列、共享内存、socket（需要 IPC）|直接读写共享变量（需要加锁）|
|创建开销|大|小|

**所属知识点：** 计算机基础 / 操作系统 / 进程与线程。

# 2. 英文例题

Which of the following statements about processes and threads is **correct**?

A. Threads of the same process each have an independent address space.

B. Different processes share the same address space by default.

C. Threads of the same process share the address space and heap of that process.

D. Context switching between processes is always cheaper than between threads.

E. A process can contain at most one thread.

**答案：C**

**解析：** 线程共享进程的地址空间、堆、全局变量与文件描述符，只私有栈、寄存器、PC。A、B 把「谁拥有地址空间」说反了；D 把切换开销说反了（进程切换要换页表、刷 TLB）；E 与多线程的事实矛盾。

**所属知识点：** 计算机基础 / 操作系统 / 进程与线程。
