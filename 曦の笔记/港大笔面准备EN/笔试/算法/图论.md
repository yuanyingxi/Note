# 1 BFS（Breadth-First Search，广度优先搜索）

**题目方向：** BFS 最适合解决什么类型的问题？

面经没有提供具体题干和选项，因此不模拟原题，重点掌握以下知识。

**知识点：BFS**

（1）什么是 BFS？

BFS 是一种图搜索算法，从起点开始，按照距离由近到远的顺序逐层访问节点。

（2）核心特点

- 使用队列（Queue）实现。
    
- 先访问当前节点的所有邻居，再访问下一层节点。
    
- 在无权图中，可以求出起点到其他节点的最短路径。
    

（3）适用场景

- 无权图的最短路径问题。
    
- 树的层序遍历（Level Order Traversal）。
    
- 判断两个节点之间是否存在路径。
    
- 网格中的最短步数问题。
    

（4）BFS 与 DFS 的区别

|对比|BFS|DFS|
|---|---|---|
|英文全称|Breadth-First Search|Depth-First Search|
|中文|广度优先搜索|深度优先搜索|
|核心数据结构|Queue|Stack / Recursion|
|搜索方式|逐层搜索|一条路径搜索到底|
|无权图最短路径|可以保证最短|不保证最短|

**需要记住：**

BFS is suitable for finding the shortest path in an unweighted graph.

即：BFS 适合求无权图中的最短路径。
# 2 DFS（Depth-First Search，深度优先搜索）

**题目方向：** DFS 与 BFS 的区别；DFS 用什么实现。

**知识点：DFS**

（1）什么是 DFS？

从起点出发，沿着一条路径一直走到底，走不动了再回溯（backtrack）到上一个分叉点，换一条路继续。

（2）核心特点

- 用栈（Stack）或递归实现（递归本质上就是利用函数调用栈）。
- 不保证最短路径，只保证「能遍历到」。
- 空间开销取决于「最深的那条路径」：O(h)，h 为最大深度。

（3）适用场景

- 连通性判断（两个节点之间有没有路径）。
- 拓扑排序（DFS 逆后序）。
- 找环（有向图：递归栈中再次遇到同一节点即为环）。
- 回溯类问题（全排列、N 皇后、数独、迷宫）。

（4）BFS 与 DFS 的完整对比

|对比|BFS|DFS|
|---|---|---|
|英文全称|Breadth-First Search|Depth-First Search|
|核心数据结构|Queue|Stack / Recursion|
|搜索方式|逐层扩散|一条路走到底再回溯|
|无权图最短路径|**保证最短**|不保证|
|空间复杂度|O(V)（最坏存一整层）|O(h)（树高 / 最大深度）|
|典型用途|最短步数、层序遍历|连通性、拓扑排序、回溯|

**需要记住：**

BFS is suitable for finding the shortest path in an **unweighted** graph. DFS tells you whether a path exists, not how short it is.

# 3 Dijkstra 算法（单源最短路，边权非负）

**题目方向：** 边权非负的带权图中求单源最短路径，用哪个算法？

**知识点：Dijkstra**

（1）解决什么问题？

给定一个**边权非负**的带权图和一个源点 s，求 s 到所有其他点的最短距离。

（2）核心思想：贪心 + 松弛（relaxation）

维护一个「已确定最短距离」的集合 S。每轮从**未确定**的节点中取「当前距离最小」的那个加入 S，然后用它去**松弛**所有邻边：

```text
if dist[u] + w(u,v) < dist[v]:
    dist[v] = dist[u] + w(u,v)
```

（3）流程

```text
Step 1  dist[s] = 0，其余 dist = ∞
Step 2  取未确定节点中 dist 最小的 u，加入 S
Step 3  松弛 u 的所有邻边
Step 4  重复 Step 2-3，直到所有节点都进入 S
```

（4）复杂度

|实现方式|复杂度|
|---|---|
|朴素（每次线性扫最小值）|O(V²)|
|优先队列（二叉堆）|O((V + E) log V)|
|斐波那契堆|O(E + V log V)|

（5）为什么不能有负权边

Dijkstra 的正确性依赖一个前提：**一旦某个点被取出，它的最短距离就再也不会变小**。负权边会破坏这个前提——后面可能出现一条更短的路径，但该点已经被确定、不再更新。

**需要记住：**

Dijkstra works only with **non-negative** edge weights. Negative weights require Bellman-Ford.

# 4 Bellman-Ford 算法（可处理负权 + 检测负环）

**题目方向：** 边权可能为负时求单源最短路，用哪个算法？

**知识点：Bellman-Ford**

（1）核心思想：对所有边做 V − 1 轮松弛

最短路径最多包含 V − 1 条边，所以做 V − 1 轮「遍历所有边并松弛」，一定能收敛。

（2）为什么是 V − 1 轮

含 n 个顶点的简单路径最多 n − 1 条边。第 k 轮结束时，可以保证「边数 ≤ k 的最短路」都已求对。所以 V − 1 轮后全部正确。

（3）负环检测

第 V 轮再扫一遍所有边，**如果还能松弛成功**，说明存在负权环（绕一圈总权为负，可以无限变小），此时最短路无定义。

（4）复杂度

O(V · E)。

（5）与 Dijkstra 的对比

|对比|Dijkstra|Bellman-Ford|
|---|---|---|
|负权边|❌ 不支持|✅ 支持|
|负环检测|❌|✅ 第 V 轮仍能松弛即有负环|
|复杂度|O((V+E) log V)|O(V·E)|
|核心动作|取最小 + 松弛|全部边反复松弛 V−1 轮|

**需要记住：**

Bellman-Ford relaxes **all** edges **V − 1** times; if the V-th round still relaxes, there is a **negative cycle**.

# 5 Floyd-Warshall 算法（全源最短路）

**题目方向：** 求任意两点之间的最短路径，用哪个算法？

**知识点：Floyd**

（1）解决什么问题？

求**所有点对**之间的最短距离（all-pairs shortest paths）。允许负权边，但不允许负环。

（2）核心：三重循环 + 动态规划

```text
for k in 1..V:              // 中间点
    for i in 1..V:          // 起点
        for j in 1..V:      // 终点
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

含义：dist[i][j] 表示「只允许经过前 k 个点作为中间点」时 i 到 j 的最短距离。

（3）k 必须在最外层

这是最容易考的实现细节。k 表示「允许使用哪些点作为中转」，是一个**阶段**；如果 k 放在内层，同一个阶段内会用尚未更新的状态去更新，结果错误。

（4）复杂度与适用规模

O(V³)，空间 O(V²)。适合稠密图、小规模（V ≤ 几百）。

**需要记住：**

In Floyd-Warshall, the loop over the **intermediate vertex k must be the outermost** loop.

# 6 Prim 与 Kruskal（最小生成树 MST）

**题目方向：** 求连接所有点且总权最小，用哪个算法？

**知识点：最小生成树**

（1）MST 是什么？

在**连通无向带权图**中，选出一棵包含全部顶点、边权之和最小的树（恰好 V − 1 条边，无环）。

（2）Prim：从一个点「长」出一棵树

```text
Step 1  任选一个起点加入树
Step 2  在所有「一端在树内、一端在树外」的边中，选权最小的那条
Step 3  把该边和树外端点加入树
Step 4  重复 V − 1 次
```

复杂度：朴素 O(V²)；用优先队列 O(E log V)。适合**稠密图**。

（3）Kruskal：按边权从小到大加边，不成环就加

```text
Step 1  把所有边按权值升序排序
Step 2  依次取出每条边，若两个端点不在同一连通块（用并查集判断），则加入
Step 3  选够 V − 1 条边即结束
```

复杂度：O(E log E)（排序主导）。适合**稀疏图**。

（4）MST ≠ 最短路（最容易被混淆的一点）

|对比|最短路（Shortest Path）|最小生成树（MST）|
|---|---|---|
|目标|两点之间路径最短|连通所有点、总权最小|
|结果|一条路径|一棵树（V − 1 条边）|
|算法|Dijkstra / Bellman-Ford / Floyd|Prim / Kruskal|
|反例|MST 上两点之间的路径往往**不是**最短路|—|

**需要记住：**

Prim builds the tree from a **vertex**; Kruskal sorts the **edges** and uses **Union-Find**. MST is not the same problem as shortest path.

# 7 Topological Sort（拓扑排序）

**题目方向：** 有向无环图（DAG）中如何确定先后顺序？

**知识点：Topological Sort**

（1）解决什么问题？

把 DAG 的所有顶点排成一个线性序列，使每条有向边 u → v 中 u 都排在 v 前面。典型场景：课程安排、编译依赖、任务调度。

（2）前提：必须是 DAG

有环就没有拓扑序（互相依赖，谁也排不到前面）。

（3）两种实现

|方法|做法|数据结构|
|---|---|---|
|Kahn 算法|反复取出**入度为 0** 的点，删除它的出边（邻点入度 −1）|**队列**|
|DFS 逆后序|DFS 后序的**逆序**即为拓扑序|栈 / 递归|

（4）用 Kahn 检测环

若最后输出的顶点数 < V，说明剩下的点入度都不为 0，即存在环。

（5）复杂度

O(V + E)。

**需要记住：**

Topological sorting applies only to a **DAG**; Kahn's algorithm uses a **queue** of zero-indegree vertices.

# 8 图算法选型对照表（这张表覆盖所有图论选择题）

|题干关键词|算法|适用图|复杂度|
|---|---|---|---|
|shortest path, **unweighted**|**BFS**|无权|O(V + E)|
|shortest path, single source, **non-negative**|**Dijkstra**|边权 ≥ 0|O((V+E) log V)|
|shortest path, **negative** weights / detect negative cycle|**Bellman-Ford**|允许负权|O(V·E)|
|shortest paths **between all pairs**|**Floyd**|允许负权、无负环|O(V³)|
|**minimum spanning tree** / connect all with min cost|**Prim / Kruskal**|连通无向带权|O(E log V) / O(E log E)|
|**DAG** / prerequisites / dependency order|**拓扑排序**|有向无环|O(V+E)|
|连通性 / 有没有路径|**DFS / BFS**|任意|O(V+E)|

（1）四个容易混淆的点

- BFS 只看「边数」，所以边权不等时它给的不是最短路；边权全相等时 BFS 等价于退化的 Dijkstra。
- Dijkstra 用**优先队列**，不是普通队列——它按「当前距离最小」出队，而不是「最早发现」。
- Kruskal 求的是 MST，不是最短路；两者的目标完全不同。
- 拓扑排序处理的是「顺序」，与距离无关。

（2）英文例题

Which algorithm finds the shortest paths from a single source in a weighted graph with **non-negative** edge weights?

A. BFS

B. DFS

C. Dijkstra's algorithm

D. Kruskal's algorithm

E. Topological sorting

**答案：C**

**解析：** BFS 只能处理无权图（按边数分层，忽略权值）；DFS 与最短路无关；Kruskal 求最小生成树；拓扑排序只针对 DAG 的先后顺序。题干两个关键词 `single source` + `non-negative` 直接锁定 Dijkstra。

**所属知识点：** 数据结构与算法 / 图论 / 最短路与最小生成树。
