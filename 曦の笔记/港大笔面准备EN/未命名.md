## 7.1 What is the relationship between a binary tree node's index and its level?

**英文题目：**

In a binary tree represented using an array, what is the relationship between a node's index and its level?

**中文题目：**

在使用数组表示的二叉树中，节点的序号和所在层数有什么关系？

**知识点：**

这里主要考查完全二叉树的数组表示（Array Representation of a Complete Binary Tree）。

假设根节点编号从 1 开始：

|节点位置|编号|
|---|---|
|根节点|1|
|左孩子|2i|
|右孩子|2i + 1|
|父节点|floor(i / 2)|

其中 i 表示当前节点的编号。

**每层节点编号范围：**

|层数|最小编号|最大编号|
|---|---|---|
|第 1 层|1|1|
|第 2 层|2|3|
|第 3 层|4|7|
|第 4 层|8|15|
|第 5 层|16|31|

规律：

第 k 层的节点编号范围：

2^(k-1) 到 2^k - 1

**English Answer:**

For a binary tree represented using an array, we usually assign index 1 to the root.

For a node at index i:

- Its left child is at index 2i.
    
- Its right child is at index 2i + 1.
    
- Its parent is at index floor(i / 2).
    

The nodes at level k have indices from 2^(k-1) to 2^k - 1.

**中文回答：**

使用数组表示二叉树时，通常将根节点编号设为 1。

对于编号为 i 的节点：

- 左孩子编号为 2i。
    
- 右孩子编号为 2i + 1。
    
- 父节点编号为 floor(i / 2)。
    

第 k 层节点的编号范围为 2^(k-1) 到 2^k - 1。

**补充：**

如果二叉树共有 h 层，那么最多有：

2^h - 1

个节点。

这里 h 表示层数，而不是边数。如果用边数表示树高，则需要注意相差 1。

## 7.2 What are the characteristics of a singly linked list?

**英文题目：**

What are the main characteristics of a singly linked list?

**中文题目：**

单链表有哪些主要特点？

**知识点：**

单链表（Singly Linked List）由多个节点组成，每个节点包含：

1. Data：数据域。
    
2. Next：指针域，指向下一个节点。
    

结构：

```
Head
 |
 v
+------+------+
| Data | Next |---->
+------+------+
                  |
                  v
             +------+------+
             | Data | Next |---->
             +------+------+
                                |
                                v
                           +------+------+
                           | Data | NULL |
                           +------+------+
```

主要特点：

|操作|时间复杂度|说明|
|---|---|---|
|访问指定位置|O(n)|必须从头节点开始遍历|
|查找元素|O(n)|需要逐个比较|
|头部插入|O(1)|只需要修改指针|
|已知前驱节点后的插入|O(1)|修改相关指针|
|已知前驱节点后的删除|O(1)|修改相关指针|

**English Answer:**

A singly linked list is a linear data structure consisting of nodes.

Each node contains two parts: data and a pointer to the next node.

Unlike an array, elements in a linked list are not stored in consecutive memory locations.

Its main advantages are efficient insertion and deletion when the relevant node is known.

However, accessing an element requires sequential traversal, so random access takes O(n) time.

**中文回答：**

单链表是一种由多个节点组成的线性数据结构。

每个节点包含数据域和一个指向下一个节点的指针。

与数组不同，链表中的元素不需要存储在连续的内存位置。

它的主要优点是在已知相关节点的情况下，可以高效地进行插入和删除操作。

但是，访问元素需要顺序遍历，因此随机访问的时间复杂度为 O(n)。

## 7.3 Which data structure is most suitable for BFS?

**英文题目：**

Which data structure is most suitable for Breadth-First Search (BFS)?

**中文题目：**

广度优先搜索 BFS 最适合使用什么数据结构？

**答案：Queue（队列）。**

**知识点：**

BFS：Breadth-First Search，广度优先搜索。

它按照距离起始节点由近到远的顺序遍历节点。

使用队列的原因：

队列遵循 FIFO：

First In, First Out，即先进先出。

**遍历过程：**

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

BFS 遍历结果：

```
A -> B -> C -> D -> E -> F
```

**English Answer:**

A queue is the most suitable data structure for BFS.

BFS explores nodes level by level, starting from the source node.

A queue follows the First-In-First-Out principle.

When we visit a node, we add its unvisited neighbors to the queue. Then, we process the nodes in the order they were added.

**中文回答：**

队列是 BFS 最适合使用的数据结构。

BFS 从起始节点开始，按照层次依次访问节点。

队列遵循先进先出的原则。

访问一个节点时，我们会将它尚未访问的邻居加入队列，然后按照加入顺序继续处理这些节点。

## 7.4 What are the basic relationships between sets?

**英文题目：**

Given several sets, identify the correct subset relationships.

**中文题目：**

给出几个集合，判断它们之间正确的包含关系。

**知识点：**

常见集合关系：

|符号|英文|中文|
|---|---|---|
|A ⊆ B|A is a subset of B|A 是 B 的子集|
|A ⊂ B|A is a proper subset of B|A 是 B 的真子集|
|A ∪ B|Union|并集|
|A ∩ B|Intersection|交集|
|A ∅|Empty set|空集|
|A = B|Equal sets|相等集合|

重要性质：

1. 空集是任意集合的子集：
    
    ∅ ⊆ A
    
2. 任意集合都是自身的子集：
    
    A ⊆ A
    
3. 如果 A ⊆ B，那么：
    
    A ∩ B = A
    
    A ∪ B = B
    
4. 如果 A ⊂ B，那么 A 是 B 的真子集，也就是说 A 不等于 B。
    

**Example:**

A = {1, 2}

B = {1, 2, 3}

C = {2, 3}

那么：

A ⊆ B

C ⊆ B

A ∩ C = {2}

A ∪ C = {1, 2, 3}

**English Answer:**

A is a subset of B if every element in A is also an element of B.

If A is a proper subset of B, A must be a subset of B and A cannot be equal to B.

The empty set is a subset of every set.

**中文回答：**

如果集合 A 中的所有元素都属于集合 B，那么 A 就是 B 的子集。

如果 A 是 B 的真子集，那么 A 必须是 B 的子集，并且 A 不能等于 B。

空集是任意集合的子集。

# 8. 数学与概率统计（Mathematics & Probability）

## 8.1 Five people stand in a line. Two specific people must stand next to each other. How many arrangements are possible?

**英文题目：**

Five people stand in a line. Two specific people must stand next to each other. How many different arrangements are possible?

**中文题目：**

五个人排成一排，其中有两个人必须挨在一起，一共有多少种排列方案？

**知识点：**

捆绑法（Grouping Method）。

当两个元素必须相邻时，可以先把它们看成一个整体，再进行排列。

**解题过程：**

假设五个人分别是：

A、B、C、D、E。

其中 A 和 B 必须相邻。

第一步：将 A、B 看成一个整体。

那么现在有四个排列单位：

(AB)、C、D、E。

四个单位的排列数为：

4! = 24

第二步：考虑 A 和 B 内部的排列。

AB 或 BA。

因此有：

2! = 2

总排列数：

4! × 2! = 24 × 2 = 48

**English Answer:**

We can treat the two people who must stand together as one single unit.

Then we have four units to arrange, so there are 4! possible arrangements.

Within the combined unit, the two people can switch their positions in 2! ways.

Therefore, the total number of arrangements is:

4! × 2! = 48.

**最终答案：48。**

## 8.2 A die has one red face, one blue face, and four black faces. What is the probability of getting either red or blue in each of the first five rolls?

**英文题目：**

A die has one red face, one blue face, and four black faces. What is the probability that each of the first five rolls results in either red or blue?

**中文题目：**

一个骰子有一个红色面、一个蓝色面和四个黑色面。连续投掷五次，每次都得到红色或蓝色的概率是多少？

**知识点：**

古典概型（Classical Probability）和独立事件（Independent Events）。

第一步：计算单次投掷成功的概率。

总共六个面，其中红色和蓝色有两个面。

P(红色或蓝色) = 2/6 = 1/3

第二步：计算连续五次都成功的概率。

每次投掷互相独立，因此：

P = (1/3)^5

= 1/243

**English Answer:**

There are six faces in total.

Two of them are favorable outcomes: one red face and one blue face.

Therefore, the probability of getting either red or blue in one roll is:

2/6 = 1/3.

Since the five rolls are independent, the required probability is:

(1/3)^5 = 1/243.

**最终答案：1/243。**

## 8.3 Vaccine probability problem（贝叶斯概率问题）

**英文题目：**

There are 1,609 people in total. Among them, 1,017 have been vaccinated and 592 have not been vaccinated.

Among the unvaccinated people, 94 tested positive for COVID-19. Among the vaccinated people, 15 tested positive.

If a person is randomly selected from those who tested positive, what is the probability that this person has been vaccinated?

**中文题目：**

共有 1609 个人，其中 1017 人接种了疫苗，592 人没有接种疫苗。

没有接种疫苗的人中，有 94 人感染；接种疫苗的人中，有 15 人感染。

现在从所有感染的人中随机选一个人，求这个人接种过疫苗的概率。

**知识点：**

条件概率（Conditional Probability）。

题目问的是：

P(已接种 | 已感染)

注意：不是 P(已感染 | 已接种)。

第一步：计算感染总人数。

感染总人数：

94 + 15 = 109

第二步：计算感染且已经接种的人数。

15 人。

第三步：计算条件概率。

P(已接种 | 已感染) = 15 / 109

≈ 0.1376

≈ 13.76%

**English Answer:**

First, we calculate the total number of infected people.

There are 94 unvaccinated infected people and 15 vaccinated infected people.

Therefore, the total number of infected people is:

94 + 15 = 109.

Among these 109 people, 15 have been vaccinated.

Thus, the required probability is:

15 / 109 ≈ 13.76%.

**最终答案：约 13.76%。**

**易错点：**

题目说的是在已经感染的人中抽取，而不是从所有人中抽取。

所以分母应该是 109，而不是 1609。

## 8.4 Calculate the integral of x cos(2x).

**英文题目：**

Calculate the following indefinite integral:

∫ x cos(2x) dx

**中文题目：**

求不定积分：

∫ x cos(2x) dx

**知识点：**

分部积分法（Integration by Parts）。

公式：

∫ u dv = uv - ∫ v du

**解题过程：**

令：

u = x

dv = cos(2x) dx

那么：

du = dx

v = 1/2 sin(2x)

代入分部积分公式：

∫ x cos(2x) dx

= x × 1/2 sin(2x) - ∫ 1/2 sin(2x) dx

继续计算：

= x/2 sin(2x) + 1/4 cos(2x) + C

**English Answer:**

We use integration by parts.

Let:

u = x

dv = cos(2x) dx

Then:

du = dx

v = sin(2x)/2

Applying the integration by parts formula:

∫ x cos(2x) dx

= x sin(2x)/2 + cos(2x)/4 + C

**最终答案：**

∫ x cos(2x) dx = x sin(2x)/2 + cos(2x)/4 + C

## 8.5 Find the second derivative of sin(sin(4x)).

**英文题目：**

Find the second derivative of the following function:

f(x) = sin(sin(4x))

**中文题目：**

求函数 sin(sin(4x)) 的二阶导数。

**知识点：**

链式法则（Chain Rule）。

对于复合函数：

y = sin(u)

则：

dy/dx = cos(u) × du/dx

**解题过程：**

第一步：求一阶导数。

f(x) = sin(sin(4x))

外层函数为 sin(u)，内层函数为 sin(4x)。

根据链式法则：

f'(x) = cos(sin(4x)) × 4cos(4x)

所以：

f'(x) = 4cos(4x)cos(sin(4x))

第二步：求二阶导数。

对一阶导数使用乘积法则（Product Rule）：

f''(x) = 4cos(4x)cos(sin(4x))'

这里需要对两个函数相乘进行求导。

最终：

f''(x) = -16sin(4x)cos(sin(4x)) - 16cos²(4x)sin(sin(4x))

**English Answer:**

First, we use the chain rule to calculate the first derivative.

f'(x) = 4cos(4x)cos(sin(4x))

Then, we apply the product rule to calculate the second derivative.

The final result is:

f''(x) = -16sin(4x)cos(sin(4x)) - 16cos²(4x)sin(sin(4x))

## 9.1 Read pseudocode and count the number of operations.

**英文题目：**

Read a piece of pseudocode and determine how many times a particular operation is executed.

**中文题目：**

阅读一段伪代码，统计某个操作或查询执行了多少次。

**知识点：**

这类题目主要考查：

- Nested Loop：嵌套循环。
    
- Condition：条件判断。
    
- Counter：计数器。

**解题方法：**

第一步：明确题目要统计什么。

例如，统计：

- 循环执行次数。
    
- 某个 if 条件成立的次数。

**中文回答：**

首先，我会确定题目要求统计哪个操作。

然后按照程序执行顺序逐步模拟，注意循环边界和条件判断。

如果存在嵌套循环，就需要计算每一层循环的执行次数。

最后统计目标操作实际执行的次数，并给出结果。

**常见循环次数：**

```
for i in range(n):
    print(i)
```

执行 n 次。

```
for i in range(n):
    for j in range(n):
        print(i, j)
```

执行 n × n = n² 次。

```
for i in range(n):
    for j in range(i):
        print(i, j)
```

执行次数：

0 + 1 + 2 + ... + (n-1)

= n(n-1)/2

时间复杂度为 O(n²)。

注意：实际题目如果存在 break、continue 或条件判断，需要根据具体代码计算，不能直接套用循环次数。

## 9.2 Read a C program related to sorting.

**英文题目：**

Read a C program that implements a sorting algorithm and determine its output or explain how it works.

**中文题目：**

阅读一段 C 语言排序代码，判断程序输出或者解释排序过程。

**知识点：**

需要认识以下基础知识：

|C 语言语法|作用|
|---|---|
|int|整数类型|
|int arr[]|整数数组|
|for|循环|
|if|条件判断|
|arr[i]|访问数组元素|
|temp|临时变量|
|swap|交换元素|

常见排序算法：

- Bubble Sort：冒泡排序。
    
- Selection Sort：选择排序。
    
- Insertion Sort：插入排序。
    
- Quick Sort：快速排序。
    
- Merge Sort：归并排序。
    

**Example：冒泡排序（Bubble Sort）**

```
#include <stdio.h>

int main() {
    int arr[] = {5, 3, 8, 1, 2};
    int n = 5;
    int temp;

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {

            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }

        }
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    return 0;
}
```

**输出：**

```
1 2 3 5 8
```

**English Answer:**

This program implements Bubble Sort.

It repeatedly compares two adjacent elements and swaps them if they are in the wrong order.

After each pass, the largest unsorted element moves to its correct position.

The average and worst-case time complexity is O(n²).

**中文回答：**

这段程序实现了冒泡排序。

它会反复比较相邻的两个元素，如果顺序不正确，就交换它们的位置。

每一轮结束后，当前未排序部分中最大的元素会移动到正确的位置。

它的平均和最坏时间复杂度为 O(n²)。

## 9.3 Find three numbers whose sum is closest to a target.

**英文题目：**

Given an integer array nums and an integer target, find three integers in nums whose sum is closest to target.

Return the sum of the three integers.

**中文题目：**

给定一个整数数组 nums 和一个目标值 target，找出数组中三个整数，使它们的和最接近 target。

返回这三个整数的和。

**知识点：**

这道题可以使用：

- Sorting：排序。
    
- Two Pointers：双指针。
    
- Three Sum：三数之和问题。
    

**解题思路：**

第一步：将数组排序。

第二步：固定一个数字 nums[i]。

第三步：使用左右指针寻找另外两个数字。

- left = i + 1
    
- right = len(nums) - 1
    

第四步：计算三数之和。

sum = nums[i] + nums[left] + nums[right]

第五步：判断当前结果与 target 的差距。

- 如果更接近，就更新答案。
    
- 如果 sum 小于 target，左指针向右移动。
    
- 如果 sum 大于 target，右指针向左移动。
    
- 如果 sum 等于 target，直接返回。
    

**Python Code：**

```
def three_sum_closest(nums, target):
    if len(nums) < 3:
        raise ValueError("At least three numbers are required")

    nums.sort()

    closest = nums[0] + nums[1] + nums[2]

    for i in range(len(nums) - 2):

        left = i + 1
        right = len(nums) - 1

        while left < right:

            current_sum = nums[i] + nums[left] + nums[right]

            if abs(current_sum - target) < abs(closest - target):
                closest = current_sum

            if current_sum < target:
                left += 1

            elif current_sum > target:
                right -= 1

            else:
                return current_sum

    return closest


# Test 1
nums = [-1, 2, 1, -4]
target = 1

print(three_sum_closest(nums, target))
```

**输出：**

```
2
```

解释：

选择：

- -1
    
- 2
    
- 1
    

它们的和是：

-1 + 2 + 1 = 2

与 target = 1 的差距为 1。

**Test 2：**

输入：

```
nums = [0, 0, 0]
target = 1

print(three_sum_closest(nums, target))
```

输出：

```
0
```

**English Answer:**

I would first sort the array.

Then, I would fix one number and use two pointers to find the other two numbers.

If the current sum is smaller than the target, I move the left pointer to the right.

If the current sum is larger than the target, I move the right pointer to the left.

During the process, I keep track of the sum that is closest to the target.

The time complexity is O(n²), including the sorting step.

**中文回答：**

首先，我会对数组进行排序。

然后固定一个数字，并使用双指针寻找另外两个数字。

如果当前和小于目标值，就将左指针向右移动。

如果当前和大于目标值，就将右指针向左移动。

在整个过程中，我会记录与目标值最接近的三数之和。

整体时间复杂度为 O(n²)。

## 9.4 Given n dice, each with m faces numbered from 1 to m, how many ways can produce a total sum of x?

**英文题目：**

You are given n dice, and each die has m faces numbered from 1 to m.

Given a target sum x, calculate the number of possible ways to roll the n dice so that the total sum is exactly x.

**中文题目：**

有 n 个骰子，每个骰子有 m 个面，点数分别为 1 到 m。

给定一个目标总点数 x，计算投掷这 n 个骰子后，总点数恰好为 x 的不同方案数。

**知识点：**

动态规划（Dynamic Programming）。

这里的每一种投掷顺序都算一种不同的方案。

例如：

两个骰子投出总和 7：

(1,6)

(2,5)

(3,4)

(4,3)

(5,2)

(6,1)

总共 6 种。

**解题思路：**

定义：

dp[i][s] 表示前 i 个骰子投出的总点数为 s 的方案数。

初始条件：

dp[0][0] = 1

表示没有投掷任何骰子时，总点数为 0 的方案只有一种，即什么都不做。

状态转移：

假设第 i 个骰子投出了 face 点。

那么：

dp[i][s] += dp[i-1][s-face]

其中：

face 从 1 到 m。

**Python Code：**

```
def count_ways(n, m, x):

    # Impossible target sums
    if x < n or x > n * m:
        return 0

    # dp[s]: number of ways to get sum s
    dp = [0] * (x + 1)

    # Initially, zero dice produce sum zero in one way
    dp[0] = 1

    # Process each die
    for i in range(n):

        new_dp = [0] * (x + 1)

        for s in range(x + 1):

            for face in range(1, m + 1):

                if s + face <= x:
                    new_dp[s + face] += dp[s]

        dp = new_dp

    return dp[x]


# Test
n = 2
m = 6
x = 7

print(count_ways(n, m, x))
```

**输出：**

```
6
```

**复杂度分析：**

时间复杂度：

O(n × x × m)

空间复杂度：

O(x)

**English Answer:**

I would solve this problem using dynamic programming.

Let dp[i][s] represent the number of ways to obtain a total sum of s using the first i dice.

Initially, dp[0][0] = 1 because there is exactly one way to obtain zero without rolling any dice.

For each new die, we consider all possible face values from 1 to m.

If the current face value is k, we update:

dp[i][s] += dp[i-1][s-k].

After processing all n dice, the answer is dp[n][x].

**中文回答：**

我会使用动态规划解决这个问题。

定义 dp[i][s] 表示使用前 i 个骰子得到总点数 s 的方案数量。

初始状态为 dp[0][0] = 1，因为不投掷骰子得到总点数 0 只有一种方案。

对于每一个新骰子，我们枚举它可能出现的点数 1 到 m。

如果当前骰子的点数为 k，那么状态转移为：

dp[i][s] += dp[i-1][s-k]。

处理完所有 n 个骰子后，最终答案就是 dp[n][x]。

# 14. 面试回答的核心原则

|考查方向|教授想了解什么|
|---|---|
|Personal Motivation|是否了解项目，以及申请动机是否明确|
