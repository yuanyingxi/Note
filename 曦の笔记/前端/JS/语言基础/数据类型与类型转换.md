# 1. JavaScript 数据类型
## 1.1 基本类型与引用类型

JavaScript 的数据类型通常分为两类：

**基本类型（Primitive Types）**：共有 7 种。

| 类型          | 含义         | 示例             |
| ----------- | ---------- | -------------- |
| `number`    | 数字，包括整数和小数 | `10`、`3.14`    |
| `string`    | 字符串        | `"hello"`      |
| `boolean`   | 布尔值        | `true`、`false` |
| `undefined` | 未定义的值      | `undefined`    |
| `null`      | 表示空值       | `null`         |
| `symbol`    | 表示唯一标识值    | `Symbol("id")` |
| `bigint`    | 表示任意精度的整数  | `123n`         |

**引用类型（Reference Types）**：通常指对象类型 `Object` 及其具体形式，例如：

- 普通对象：`{}`
    
- 数组：`[]`
    
- 函数：`function() {}`
    
- 日期对象：`new Date()`
    

注意：数组、函数、日期都属于对象相关的类型，并不是额外增加的三种基本类型。

## 1.2 基本类型与引用类型的区别

两者在赋值和比较时有重要区别。

### 1.2.1 基本类型：赋值时复制值

```js
let a = 10;
let b = a;

b = 20;

console.log(a); // 10
console.log(b); // 20
```

`b = a` 将 `a` 的值复制给 `b`。修改 `b` 不会影响 `a`。

### 1.2.2 引用类型：赋值时复制对象的引用

```js
let obj1 = { name: "张三" };
let obj2 = obj1;

obj2.name = "李四";

console.log(obj1.name); // "李四"
```

`obj1` 和 `obj2` 指向同一个对象，因此通过 `obj2` 修改对象属性后，通过 `obj1` 也能看到修改结果。

可以理解为：

```text
obj1 ──┐
       ├──> 同一个对象 { name: "李四" }
obj2 ──┘
```

如果重新给 `obj2` 赋值为另一个对象，则不会改变 `obj1` 的指向。

**记忆重点：** 基本类型赋值后，修改其中一个变量不会改变另一个变量的值；引用类型赋值后，两个变量可能引用同一个对象，修改该对象的属性会相互影响。

# 2. null 与 undefined

两者都表示没有正常的具体数据，但含义不同。

|对比项|`undefined`|`null`|
|---|---|---|
|含义|尚未定义值或当前没有可用值|明确表示空值|
|常见场景|变量声明后未赋值|开发者主动表示没有对象或数据|
|`typeof` 结果|`"undefined"`|`"object"`|

## 2.1 undefined 的常见场景

```js
// 声明变量但未赋值
let a;
console.log(a); // undefined

// 访问不存在的对象属性
const user = {};
console.log(user.name); // undefined

// 函数没有返回值
function test() {}
console.log(test()); // undefined
```

### 2.2 null 的常见场景

```js
let user = null;
```

这里明确表示 `user` 当前没有关联的用户对象。

例如，查询用户信息时，开发者可以用 `null` 表示当前没有选中的用户。

### 2.3 typeof null 为什么是 object？

```js
console.log(typeof null);      // "object"
console.log(typeof undefined); // "undefined"
```

`typeof null` 返回 `"object"` 是 JavaScript 早期遗留的历史问题，为了兼容现有代码，至今保留了这一行为。

判断 `null` 时，可以直接使用：

```js
if (user === null) {
  console.log("当前没有用户");
}
```

**记忆重点：** `undefined` 通常表示没有赋值或没有对应的值，`null` 通常表示开发者明确设置了空值。不要使用 `typeof` 来判断一个值是否为 `null`。

# 3. typeof：判断数据类型

`typeof` 是 JavaScript 提供的运算符，可以查看一个值所属的类型。

```js
typeof 123;          // "number"
typeof "hello";      // "string"
typeof true;         // "boolean"
typeof undefined;    // "undefined"
typeof Symbol("id"); // "symbol"
typeof 123n;         // "bigint"
typeof {};           // "object"
typeof [];           // "object"
typeof null;         // "object"
typeof function() {}; // "function"
```

注意：

1. `typeof` 不能直接区分**普通对象和数组**，因为两者的结果都是 `"object"`。
    
2. 判断数组应使用 `Array.isArray()`。
    
3. `typeof null` 的结果是 `"object"`，属于历史遗留行为。
    

示例：

```js
console.log(Array.isArray([]));  // true
console.log(Array.isArray({}));  // false
```

# 4. \==、=== 与 Object.is
## 4.1 == 与 === 的区别

`==` 和 `===` 都用于比较两个值是否相等，但处理类型不同的值时，行为不同。

|运算符|名称|是否进行隐式类型转换|
|---|---|---|
|`==`|宽松相等|可能会|
|`===`|严格相等|不会|

例如：

```js
console.log(1 == "1");  // true
console.log(1 === "1"); // false

console.log(true == 1);  // true
console.log(true === 1); // false
```

使用 `==` 时，JavaScript 会按照一定规则进行类型转换，因此不同类型的值也可能被判断为相等。

使用 `===` 时，如果两边的类型不同，结果就是 `false`。

其他示例：

```js
console.log(null == undefined);  // true
console.log(null === undefined); // false

console.log(0 == false);  // true
console.log(0 === false); // false
```

**开发建议：** 日常业务代码优先使用 `===` 和 `!==`，避免隐式类型转换造成意外结果。

## 4.2 对象比较

**比较两个对象时，`==` 和 `===` 都是比较它们是否引用同一个对象，而不是比较对象内部的属性值**

```js
const a = { name: "张三" };
const b = { name: "张三" };
const c = a;

console.log(a === b); // false
console.log(a === c); // true
```

虽然 `a` 和 `b` 的属性值相同，但它们是两个独立对象。

而 `c = a` 使 `c` 引用 `a` 指向的同一个对象，所以 `a === c` 为 `true`。

## 4.3 Object.is 与 === 的区别

`Object.is()` 也用于判断两个值是否相同。绝大多数常见情况下，它与 `===` 的判断结果一致，但有两个特殊区别：

```js
console.log(NaN === NaN);        // false
console.log(Object.is(NaN, NaN)); // true

console.log(+0 === -0);          // true
console.log(Object.is(+0, -0));  // false
```

对于普通业务开发，优先记住 `===` 即可；知道 `Object.is()` 存在，以及它对 **`NaN` 和正负零**的处理不同即可。

# 5. JavaScript 数据类型转换

数据类型转换是指将一种类型的值转换为另一种类型。

分为两种情况：

- **显式转换**：开发者主动调用转换方法。
    
- **隐式转换**：JavaScript 在运算或比较时自动转换类型。
    

## 5.1 显式类型转换
### 5.1.1 转换为字符串

使用 `String()`：

```js
String(123);  // "123"
String(true); // "true"
String(null); // "null"
```

注意：这里是将值转换为字符串，不是将变量本身重新定义为字符串。

### 5.1.2 转换为数字

使用 `Number()`：

```js
Number("123");  // 123
Number("3.14"); // 3.14
Number(true);   // 1
Number(false);  // 0

Number("hello"); // NaN
```

**`NaN` 表示不是一个有效的数字结果。**

还要注意：

```js
Number("");   // 0
Number(null); // 0
Number(undefined); // NaN
```

因此，转换数字之前，要注意输入的数据是否为空，不能只依赖 `Number()` 判断用户是否填写了有效内容。

### 5.1.3 转换为布尔值

使用 `Boolean()`：

```js
Boolean(1);      // true
Boolean(0);      // false
Boolean("hello"); // true
Boolean("");      // false
Boolean(null);    // false
```

## 5.2 真值与假值

JavaScript 在 `if`、`while` 等条件判断中，会将值转换为布尔值。

常见假值（Falsy）如下：

|值|转换结果|
|---|---|
|`false`|`false`|
|`0`、`-0`|`false`|
|`0n`|`false`|
|`""`（空字符串）|`false`|
|`null`|`false`|
|`undefined`|`false`|
|`NaN`|`false`|

除此以外，常见的非空字符串、非零数字、数组和对象都是真值（Truthy）。

需要特别注意：

```js
Boolean("0");  // true
Boolean("false"); // true

Boolean(0);    // false
Boolean([]);   // true
Boolean({});   // true
```

**空数组和空对象也是真值**，不能因为它们看起来没有内容就认为是 `false`。

## 5.3 隐式类型转换

JavaScript 在执行某些运算时，会自动转换类型。

### 5.3.1 加法运算 +

`+` 既可以进行数字加法，也可以进行字符串拼接。

```js
console.log(1 + 2);     // 3
console.log(1 + "2");   // "12"
console.log(true + 1);  // 2
```

可以先记住：

- 如果运算过程中转换得到字符串，`+` 可能执行字符串拼接。
    
- 如果转换为数字进行加法，结果就是数值相加。
    
- `true` 转换为数字是 `1`，`false` 转换为数字是 `0`。
    

### 5.3.2 减法、乘法、除法

这些运算通常会将操作数转换为数字。

```js
console.log("5" - 2); // 3
console.log("5" * 2); // 10
console.log("6" / 2); // 3
```

### 5.3.3 比较运算

混合不同类型进行比较时，要注意 JavaScript 的转换规则。

```js
console.log("10" > 9);  // true
console.log("10" > "9"); // false
```

第一个例子比较的是数值大小，因此 `"10"` 会转换为数字 `10`。

第二个例子两边都是字符串，按照字符串的字典序比较，所以 `"10"` 小于 `"9"`。

业务开发中，如果数值来自表单或接口，应先确认数据类型，需要按数值大小比较时，应显式转换为数字。

## 5.4 ToPrimitive：了解即可

当 JavaScript 需要将对象参与基本运算时，可能会先将对象转换为基本类型，这个过程称为 `ToPrimitive`。

例如：

```js
console.log([] + []); // ""
console.log([] + 1);  // "1"
```

数组参与 `+` 运算时，会转换为基本值；空数组转换为字符串后是空字符串，所以两个空数组相加得到 `""`。

这个机制涉及对象的 `valueOf()`、`toString()` 等方法。

基础复习阶段不必背诵完整的内部算法，能理解**对象参与运算时可能发生隐式类型转换**即可。

# 6. Symbol 与 BigInt

这两种类型了解基本用途即可，不必深入内部机制。

## 6.1 Symbol：创建唯一标识值

`Symbol` 用于创建**具有唯一身份的值**，即使描述字符串相同，创建结果也不相等。

```js
const a = Symbol("id");
const b = Symbol("id");

console.log(a === b); // false
```

常见用途是**作为对象属性的键**，避免与其他属性名发生冲突。

```js
const key = Symbol("id");

const user = {
  name: "张三",
  [key]: 123
};

console.log(user[key]); // 123
```

注意：

- `Symbol("id")` 创建的值具有唯一身份。
    
- `Symbol.for("id")` 会使用全局 Symbol 注册表，相同键名可以取得同一个 Symbol。
    
- Symbol 属性键通常不会被 `JSON.stringify()` 序列化。
    

对于基础岗位，掌握 Symbol 的**唯一性**和基本用途即可。

## 6.2 BigInt：表示大整数

普通 `Number` 无法**精确**表示所有整数。

JavaScript 的最大安全整数是：

```js
Number.MAX_SAFE_INTEGER;
// 9007199254740991
```

当需要精确处理超过安全整数范围的整数时，可以使用 `BigInt`。

```js
const a = 9007199254740993n;
const b = 1n;

console.log(a + b); // 9007199254740994n
```

数字末尾的 `n` 表示这是一个 `BigInt` 值。

注意：

```js
const a = 10n;
const b = 2;

// a + b; // 报错，不能直接混合运算
console.log(a + BigInt(b)); // 12n
```

另外，`BigInt` 不能直接由 `JSON.stringify()` 序列化：

```js
JSON.stringify({ id: 123n }); // 抛出 TypeError
```

在前后端接口中，超长 ID 通常更适合由后端以字符串形式返回，避免 JavaScript 的数字精度问题。

# 7. 浮点数精度问题
## 7.1 为什么 0.1 + 0.2 不等于 0.3？

```js
console.log(0.1 + 0.2);
// 0.30000000000000004

console.log(0.1 + 0.2 === 0.3);
// false
```

这是因为 JavaScript 的 `Number` 使用 IEEE 754 双精度浮点数表示数字。

**某些十进制小数无法被二进制浮点数精确表示，因此运算会产生微小的舍入误差。**

## 7.2 如何处理精度问题？
### 7.2.1 格式化显示

```js
const result = (0.1 + 0.2).toFixed(2);

console.log(result); // "0.30"
```

注意：`toFixed()` 返回的是**字符串**，主要用于格式化显示，并不意味着底层运算误差已经消失。

### 7.2.2 金额计算使用整数

例如，金额以分为单位进行运算：

```js
const priceCents = 1999; // 19.99 元
const quantity = 3;

const totalCents = priceCents * quantity;

console.log(totalCents); // 5997
console.log((totalCents / 100).toFixed(2)); // "59.97"
```

这里使用整数分计算，可以避免大多数常见的二进制小数累加问题。

但仍要注意整数范围，超过安全整数范围时需要使用合适的高精度方案。

涉及复杂金额计算时，通常应结合后端的 `BigDecimal` 等精确数值类型，或使用专门的十进制计算库，并明确舍入规则。

# 8. 常见面试问题速记
## 8.1 JavaScript 有哪些数据类型？

通常分为 7 种基本类型和 1 种对象类型。基本类型包括 `number`、`string`、`boolean`、`undefined`、`null`、`symbol` 和 `bigint`；对象类型包括普通对象、数组、函数等。

## 8.2 null 与 undefined 有什么区别？

`undefined` 通常表示没有赋值或没有对应的值；`null` 通常用于明确表示空值。

## 8.3 为什么 typeof null 返回 object？

这是 JavaScript 的历史遗留行为。判断 `null` 应使用 `value === null`。

## 8.4 == 与 === 有什么区别？

`==` 可能进行隐式类型转换，`===` 不进行这种转换。开发中一般优先使用 `===`。

## 8.5 基本类型与引用类型的赋值有什么区别？

基本类型赋值复制值；引用类型赋值复制对象的引用。如果多个变量引用同一个对象，通过其中一个变量修改对象属性，其他变量也会观察到变化。

## 8.6 JavaScript 中哪些值是假值？

常见假值包括 `false`、`0`、`-0`、`0n`、`""`、`null`、`undefined` 和 `NaN`。空数组、空对象和字符串 `"0"` 都是真值。

## 8.7 什么是隐式类型转换？

JavaScript 在运算或比较时自动转换数据类型，例如 `"5" - 2` 得到 `3`，而 `1 + "2"` 得到字符串 `"12"`。

## 8.8 为什么 0.1 + 0.2 不等于 0.3？

因为部分十进制小数无法被二进制浮点数精确表示，运算产生了舍入误差。涉及金额时，可以使用整数最小货币单位或精确十进制计算方案。

## 8.9 BigInt 有什么用途？

`BigInt` 用于精确表示超出 `Number` 安全整数范围的大整数。它不能直接与普通 `Number` 混合运算，也不能直接通过 `JSON.stringify()` 序列化。
