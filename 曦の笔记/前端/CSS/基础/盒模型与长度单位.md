# 1. 盒模型（Box Model）
## 1.1 什么是盒模型？

CSS 盒模型描述了 HTML 元素在页面中占据空间的方式。可以把每个元素理解成一个矩形盒子，由内向外分为四个部分：

```text
┌──────────────────────────────┐
│            margin            │  外边距
│   ┌──────────────────────┐   │
│   │        border        │   │  边框
│   │   ┌──────────────┐   │   │
│   │   │   padding    │   │   │  内边距
│   │   │  ┌────────┐  │   │   │
│   │   │  │content │  │   │   │  内容
│   │   │  └────────┘  │   │   │
│   │   └──────────────┘   │   │
│   └──────────────────────┘   │
└──────────────────────────────┘
```

四个部分的作用：

| 部分        | 含义                 |
| --------- | ------------------ |
| `content` | 内容区域，例如文字、图片       |
| `padding` | 内边距，内容与边框之间的距离     |
| `border`  | 边框，包围内容和内边距        |
| `margin`  | 外边距，元素与其他元素之间的外部间距 |

注意：元素的背景色通常会覆盖内容区和内边距，但不会覆盖外边距。

## 1.2 两种盒模型

CSS 有两种常见的盒模型，主要区别是 `width` 和 `height` 计算的范围不同。

| 对比项                       | 标准盒模型 `content-box` | 替代盒模型 `border-box` |
| ------------------------- | ------------------- | ------------------ |
| `width` 包含什么              | 仅内容区域               | 内容、内边距、边框          |
| 增加 `padding` 和 `border` 后 | 元素实际宽度增大            | 元素总宽度不变，内容区域缩小     |
| 是否为默认值                    | 是                   | 否                  |

### 1.2.1 标准盒模型

默认情况下，`width` 只表示内容区域的宽度。

```css
.box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

元素的实际总宽度为：

```text
内容宽度 + 左右内边距 + 左右边框

200 + 20 × 2 + 5 × 2 = 250px
```

因此，虽然设置了 `width: 200px`，但元素实际的边框总宽度是 `250px`。

### 1.2.2 替代盒模型

设置 `box-sizing: border-box` 后，`width` 就包含内容、内边距和边框。

```css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

此时元素的总宽度始终为 `200px`，内容区域的宽度为：

```text
200 - 20 × 2 - 5 × 2 = 150px
```

## 1.3 box-sizing 属性

`box-sizing` 用于指定元素采用哪种盒模型。

| 属性值           | 作用                             |
| ------------- | ------------------------------ |
| `content-box` | `width` 和 `height` 只计算内容区域     |
| `border-box`  | `width` 和 `height` 包含内容、内边距和边框 |

**现代项目通常推荐统一使用 `border-box`，因为这样更容易控制元素的最终尺寸。**

常见写法：这段代码的作用是把页面中所有 HTML 元素，以及它们的 `::before`、`::after` 伪元素，都统一设置为 `box-sizing: border-box`。

```css
*,   /* `*` 是 CSS 的通用选择器，可以选择页面中的所有 HTML 元素。*/ 
*::before,
*::after {
  box-sizing: border-box;
}
```

这段代码将盒模型统一设置为 `border-box`，包括普通元素及其伪元素。

**注意：** `box-sizing` 默认不继承，因此实际项目中经常通过通配选择器统一设置，而不是依赖继承。

## 1.4 元素总宽度和总高度的计算

在标准盒模型下：

```text
元素总宽度 =
  左外边距 + 左边框 + 左内边距
  + 内容宽度
  + 右内边距 + 右边框 + 右外边距
```

同理：

```text
元素总高度 =
  上外边距 + 上边框 + 上内边距
  + 内容高度
  + 下内边距 + 下边框 + 下外边距
```

如果使用 `border-box`，那么声明的 `width` 和 `height` 已经包含内容、内边距和边框，但**仍然不包含 margin**。

# 2. CSS 盒模型：重点补充
### 2.1 标准盒模型与替代盒模型的区别

两种盒模型的核心区别在于：**声明的** `width` **到底表示内容宽度，还是包括边框在内的总宽度。**

记忆方法：

```text
content-box：
width = 内容宽度

border-box：
width = 内容宽度 + 左右 padding + 左右 border
```

例如：

```css
.box {
  width: 200px;
  padding: 10px;
  border: 2px solid black;
}
```

|盒模型|内容宽度|边框总宽度|
|---|---|---|
|`content-box`|200px|224px|
|`border-box`|176px|200px|

计算过程：

- `content-box`：`200 + 10 × 2 + 2 × 2 = 224px`
    
- `border-box`：`200 - 10 × 2 - 2 × 2 = 176px`，这是内容区域的宽度。
    

## 2.2 为什么推荐使用 border-box？

假设一个父容器宽度为 `400px`，里面有两个子元素，每个子元素设置 `width: 200px`。

如果子元素使用标准盒模型，再添加内边距和边框，它们的实际宽度就可能超过 `200px`，导致布局溢出。

使用 `border-box` 后，子元素的边框总宽度仍然是 `200px`，**更容易实现预期布局**。

## 2.3 外边距合并：了解即可

相邻块级元素的上下外边距，有时不会简单相加，而是发生外边距合并。

例如，在特定条件下，两个相邻块级元素分别设置 `margin-bottom: 20px` 和 `margin-top: 30px`，最终间距可能是 `30px`，而不是 `50px`。

外边距合并主要发生在特定的垂直布局场景中。基础阶段先记住这个现象即可，遇到间距与预期不符时再检查。

# 3. CSS 长度单位：px、em、rem、vw、vh 等

CSS 长度单位用于设置元素的宽高、间距、字体大小等。

## 3.1 常见单位

| 单位     | 含义                   | 主要特点               |
| ------ | -------------------- | ------------------ |
| `px`   | CSS 像素               | 适合精确设置尺寸           |
| `em`   | 相对于字体大小              | 具体基准与使用它的 CSS 属性有关 |
| `rem`  | 相对于根元素的字体大小          | 基准统一，方便整体调整尺寸      |
| `%`    | 百分比                  | 相对于对应属性规定的参考尺寸计算   |
| `vw`   | 视口宽度的 1%             | 随浏览器视口宽度变化         |
| `vh`   | 视口高度的 1%             | 随浏览器视口高度变化         |
| `vmin` | `vw` 和 `vh` 中较小值的 1% | 根据较小的视口尺寸变化        |
| `vmax` | `vw` 和 `vh` 中较大值的 1% | 根据较大的视口尺寸变化        |

其中，`vw` 和 `vh` 中的视口可以简单理解为浏览器当前用于显示网页的可视区域。

例如，假设视口宽度为 `1000px`，视口高度为 `800px`：

```text
100vw = 1000px
1vw   = 10px

100vh = 800px
1vh   = 8px

100vmin = 800px
100vmax = 1000px
```

## 3.2 px：CSS 像素

`px` 是前端开发中最常见的长度单位。

```css
.box {
  width: 200px;
  height: 100px;
  font-size: 16px;
}
```

这里表示元素宽度为 `200 CSS px`、高度为 `100 CSS px`，字体大小为 `16 CSS px`。

注意：**1 CSS px 不一定等于屏幕上的 1 个物理像素。**

在高分辨率屏幕上，一个 CSS 像素可能由多个物理像素显示。因此，日常开发中可以将 `px` 理解为 CSS 使用的尺寸单位，而不是直接等同于屏幕硬件像素。

### 3.3 em：相对字体大小

`em` 的计算基准需要根据使用它的属性判断。

- 用于设置 `font-size` 时，`em` 相对于父元素的计算后字体大小。
    
- 用于设置 `padding`、`margin` 等其他长度属性时，`em` 相对于当前元素的计算后字体大小。
    

例如：

```cs
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em;
  padding: 1em;
}
```

计算结果：

```
.child 的字体大小 = 20 × 1.5 = 30px

.child 的上下左右 padding = 30 × 1 = 30px
```

如果多层嵌套元素反复使用 `em` 设置字体大小，字体尺寸可能逐层变化，需要注意累计效果。

**注：**

- **`font-size` 使用 `em` 时，相对于父元素的字体大小。**
    
- **`padding` 使用 `em` 时，相对于当前元素自身的计算后字体大小。**

## 3.4 rem：相对于根元素

`rem` 是相对于根元素 `<html>` 的计算后字体大小。

例如：

```css
html {
  font-size: 16px;
}

.title {
  font-size: 2rem;
}

.card {
  padding: 1rem;
}
```

计算结果：

```text
.title 的字体大小 = 16 × 2 = 32px

.card 的内边距 = 16 × 1 = 16px
```

如果将根元素的字体大小改为 `20px`，那么 `2rem` 就会变为 `40px`，`1rem` 就会变为 `20px`。

因此，`rem` 适合用于字体大小、间距等需要统一调整的尺寸。

## 3.5 vw 和 vh：相对于视口

`vw` 表示视口宽度的 1%，`vh` 表示视口高度的 1%。

```css
.container {
  width: 80vw;
  height: 50vh;
}
```

假设视口宽度为 `1000px`、高度为 `800px`：

```text
width  = 1000 × 80% = 800px
height = 800 × 50%  = 400px
```

常见用途：

- `vw`：设置随浏览器宽度变化的元素宽度。
    
- `vh`：设置随浏览器高度变化的容器高度。
    

注意：移动端浏览器的地址栏会影响可视区域，`vh` 在某些移动端场景下不一定等于当前实际可见高度。

# 4. 单位对比补充
## 4.1 px、em、rem 的区别

这三个单位是 CSS 基础中比较重要的内容。

|对比项|`px`|`em`|`rem`|
|---|---|---|---|
|类型|CSS 像素单位|相对单位|相对单位|
|计算基准|CSS 像素|字体大小，取决于具体属性|根元素的字体大小|
|是否受父元素字体大小影响|通常不直接受影响|设置 `font-size` 时受父元素影响|不直接受普通父元素字体大小影响|
|主要用途|精确设置尺寸|根据字体大小设置尺寸|使用统一基准控制尺寸|

示例：

```css
html {
  font-size: 16px;
}

.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em;
  padding: 1rem;
}
```

计算结果：

```text
.child 字体大小 = 20 × 1.5 = 30px

.child 内边距 = 16 × 1 = 16px
```

注意，`em` 不是任何情况下都直接相对于父元素字体大小。设置 `font-size` 与设置 `padding` 时，计算基准不同。

## 4.2 clamp()：限制尺寸范围

`clamp()` 不是长度单位，而是 CSS 提供的一个函数，可以将某个值限制在最小值和最大值之间。

基本语法：

```css
font-size: clamp(最小值, 首选值, 最大值);
```

例如：

```css
.title {
  font-size: clamp(16px, 2vw, 24px);
}
```

含义是：

- 最小字体大小为 `16px`。
    
- 首选值为 `2vw`，随着视口宽度变化。
    
- 最大字体大小为 `24px`。
    

当 `2vw` 小于 `16px` 时，使用 `16px`；大于 `24px` 时，使用 `24px`；处于两者之间时，使用 `2vw`。

## 4.3 CSS 单位怎么选择？

|使用场景|常见选择|
|---|---|
|固定尺寸、精确控制边框|`px`|
|根据字体大小调整内边距等|`em`|
|统一调整页面字号、间距|`rem`|
|根据浏览器宽度设置尺寸|`vw`|
|根据浏览器高度设置尺寸|`vh`|
|在最小值和最大值之间动态调整|`clamp()`|

实际开发中不必强行只使用一种单位，应根据具体需求选择。

# 5. 面试重点速记
## 5.1 什么是 CSS 盒模型？

CSS 盒模型描述元素占据空间的方式，由内容区、内边距、边框和外边距组成。

## 5.2 content-box 和 border-box 有什么区别？

`content-box` 的 `width` 只包含内容宽度；`border-box` 的 `width` 包含内容、内边距和边框。

## 5.3 为什么项目中经常设置 box-sizing: border-box？

这样可以让元素的声明宽度与边框总宽度保持一致，减少内边距和边框导致的布局溢出，**更容易控制元素尺寸**。

## 5.4 px、em 和 rem 有什么区别？

`px` 是 CSS 像素单位；`em` 的计算基准与使用它的属性有关，设置字体大小时相对于父元素字体大小；`rem` 相对于根元素的字体大小。

## 5.5 vw 和 vh 是什么？

`vw` 是视口宽度的 1%，`vh` 是视口高度的 1%，常用于根据浏览器视口调整元素尺寸。

## 5.6 为什么不能把 1px 理解为 1 个物理像素？

CSS 像素是 CSS 的尺寸单位。在高分辨率屏幕上，一个 CSS 像素可能对应多个物理像素。

## 5.7 em 和 rem 最大的区别是什么？

`em` 会根据字体大小计算，嵌套场景中可能逐层变化；`rem` 统一以根元素的字体大小为基准。
