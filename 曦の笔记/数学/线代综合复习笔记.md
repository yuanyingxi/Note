## 1. 矩阵维度与乘法合法性

| 结论 | 公式 / 条件 |
| --- | --- |
| 维度记法 | $m\times n$ = $m$ 行 $n$ 列；方阵 $\iff m=n$ |
| $AB$ 定义良好（well-defined） | $A_{m\times n}B_{p\times q}$ 要求 $n=p$（左列数 = 右行数），结果维度 $m\times q$ |
| 记忆式 | $(m\times n)(n\times q)=m\times q$ |
| 元素公式 | $(AB)_{ij}=\sum_k A_{ik}B_{kj}$ |
| 矩阵乘列向量 | 结果第 $i$ 个分量 = 第 $i$ 行与向量的点积；矩阵乘全 1 向量 = 各行元素和组成的向量 |
| ※ 矩阵乘行向量 | $\mathbf r^T A$ 的结果第 $j$ 个分量 = 该行向量与 $A$ 第 $j$ 列的点积 |
| ※ 分块矩阵 | 按行 / 列分块后乘法规则同普通矩阵，但各子块维度必须匹配；$\det\begin{pmatrix}A&0\\0&D\end{pmatrix}=\det(A)\det(D)$ |
| 常见错误 | 把"左列数 = 右行数"看成"行数 = 行数"；以为只有方阵才能相乘；忽略 $BA$ 可能无定义 |

## 2. 特殊矩阵与矩阵运算性质

| 性质 | 结论 |
| --- | --- |
| 结合律 | $(AB)C=A(BC)$ **恒成立**（只要各乘积定义良好） |
| 交换律 | 一般不成立：$AB\neq BA$，甚至两者维度都不同 |
| 分配律 | $A(B+C)=AB+AC$、$(A+B)C=AC+BC$ |
| 单位矩阵 | $AI=IA=A$，$I\mathbf v=\mathbf v$，$\det(I)=1$ |
| 转置 | $(A^T)^T=A$、$(A+B)^T=A^T+B^T$、$(kA)^T=kA^T$、$(AB)^T=B^TA^T$（顺序反转）、$(ABC)^T=C^TB^TA^T$ |
| 乘积的逆 | $(AB)^{-1}=B^{-1}A^{-1}$（顺序反转），$(ABC)^{-1}=C^{-1}B^{-1}A^{-1}$ |
| 转置的逆 | $(A^T)^{-1}=(A^{-1})^T$ |
| 矩阵相等 | 维度相同且对应位置元素全相等 |
| ※ 迹（trace） | $\operatorname{tr}(A)=\sum_i a_{ii}$；$\operatorname{tr}(AB)=\operatorname{tr}(BA)$、$\operatorname{tr}(A+B)=\operatorname{tr}(A)+\operatorname{tr}(B)$、$\operatorname{tr}(A)=\sum_i\lambda_i$ |
| ※ 对称矩阵 | $A^T=A$；实对称矩阵特征值全为实数、不同特征值的特征向量正交、必可正交对角化 |
| ※ 反对称矩阵 | $A^T=-A$；主对角线元素全为 0；奇数阶时 $\det(A)=0$ |
| ※ 正交矩阵 | $Q^TQ=QQ^T=I$，$Q^{-1}=Q^T$，$\det(Q)=\pm1$；保长度、保夹角、保点积 |
| ※ 对角 / 三角矩阵 | 对角矩阵的乘积与幂等于对角元素逐点运算；三角矩阵的 $\det$ 与特征值都等于主对角线元素 |
| ※ 幂等 / 幂零 / 对合 | $A^2=A$ 幂等（特征值只可能 0 或 1）；$A^k=0$ 幂零（特征值全 0）；$A^2=I$ 对合（特征值 $\pm1$） |
| ※ 置换矩阵 | 单位矩阵交换若干行所得；$P^{-1}=P^T$；用于 $PA=LU$ |

## 3. 行列式

### 3.1 计算

| 结论 | 公式 |
| --- | --- |
| 二阶 | $\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc$（主对角线积 − 副对角线积） |
| 三阶（第一行展开） | $a(ei-fh)-b(di-fg)+c(dh-eg)$ |
| 余子式（Minor） | $M_{ij}$：删去第 $i$ 行、第 $j$ 列后的行列式 |
| 代数余子式（Cofactor） | $C_{ij}=(-1)^{i+j}M_{ij}$；符号棋盘：第一行 $+,-,+,-$，第二行 $-,+,-,+$ |
| 拉普拉斯展开 | $\det(A)=\sum_j a_{ij}C_{ij}=\sum_j a_{ij}(-1)^{i+j}M_{ij}$，可沿任意一行或一列 |
| 展开位置 | 优先选含 0 最多的行 / 列，减少计算量 |
| 三角矩阵 | $\det(A)=a_{11}a_{22}\cdots a_{nn}$（主对角线之积） |
| 两行（列）相同或成比例 | $\det(A)=0$ |
| ※ 按行 / 列的线性性 | 某一行拆成两行之和时，行列式等于两个行列式之和；单行提取公因子 $k$ 时整体乘 $k$ |
| ※ 伴随矩阵 | $A\,\operatorname{adj}(A)=\operatorname{adj}(A)A=\det(A)I$；$A^{-1}=\dfrac{\operatorname{adj}(A)}{\det(A)}$ |

### 3.2 运算性质

| 运算 | 性质 |
| --- | --- |
| 乘积 | $\det(AB)=\det(A)\det(B)$；因此 $\det(AB)=\det(BA)$ |
| 转置 | $\det(A^T)=\det(A)$ |
| 求逆 | $\det(A^{-1})=1/\det(A)$（要求 $\det(A)\neq0$） |
| 数乘（$n$ 阶） | $\det(kA)=k^n\det(A)$，指数是阶数 $n$ |
| 初等行变换 | 交换两行 → 变号；某行乘 $k$ → 结果乘 $k$；某行加另一行 $k$ 倍 → 不变 |
| 加减法 | $\det(A-B)\neq\det(A)-\det(B)$；$\det(A+B)$ 无通用公式 |
| 可逆性 | $A$ 可逆 $\iff\det(A)\neq0\iff\operatorname{rank}(A)=n$；$\det(A)=0$ 为奇异矩阵（Singular） |
| ※ 与特征值 | $\det(A)=\prod_i\lambda_i$；$A$ 可逆 $\iff$ 全部特征值非零 |
| ※ 几何意义 | $\lvert\det(A)\rvert$ = 列（行）向量张成的平行六面体体积，二维时为平行四边形面积；$\det=0\iff$ 列向量线性相关 |

## 4. 秩、可逆性与四个基本子空间

| 结论 | 公式 |
| --- | --- |
| 秩 | 线性无关行（列）的最大数量 = 行阶梯形非零行数 = 主元个数 |
| 上界 | $\operatorname{rank}(A)\leq\min(m,n)$ |
| 乘积 | $\operatorname{rank}(AB)\leq\min(\operatorname{rank}(A),\operatorname{rank}(B))$ |
| 满秩 | $n\times n$ 方阵可逆 $\iff\operatorname{rank}(A)=n\iff\det(A)\neq0$ |
| 快速判不可逆 | $A$ 为 $m\times n$ 且 $n<m$ 时，$\operatorname{rank}(AB)\leq n<m$，故 $m\times m$ 的 $AB$ 必不可逆 |
| ※ 行秩 = 列秩 | $\operatorname{rank}(A)=\operatorname{rank}(A^T)$ |
| ※ 和的秩 | $\operatorname{rank}(A+B)\leq\operatorname{rank}(A)+\operatorname{rank}(B)$ |
| ※ 初等变换 | 左乘 / 右乘可逆矩阵不改变秩；$\operatorname{rank}(PAQ)=\operatorname{rank}(A)$（$P,Q$ 可逆） |
| ※ Sylvester 不等式 | $\operatorname{rank}(A)+\operatorname{rank}(B)-n\leq\operatorname{rank}(AB)$（$n$ 为内维度） |
| ※ 秩-零化度定理 | $\operatorname{rank}(A)+\dim\ker(A)=n$（$n$ 为 $A$ 的列数） |
| ※ $\operatorname{rank}(A^TA)$ | $=\operatorname{rank}(A)=\operatorname{rank}(AA^T)$，故 $A^TA$ 可逆 $\iff A$ 列满秩 |
| ※ 四个基本子空间 | 列空间 $C(A)$ 维数 $r$；零空间 $N(A)$ 维数 $n-r$；行空间 $C(A^T)$ 维数 $r$；左零空间 $N(A^T)$ 维数 $m-r$；$C(A)\perp N(A^T)$、$C(A^T)\perp N(A)$ |
| ※ 可逆等价条件汇总 | $\det(A)\neq0$；$\operatorname{rank}=n$；列（行）线性无关；$A\mathbf x=\mathbf 0$ 只有零解；行阶梯形无零行；全部特征值非零；$A$ 可写成初等矩阵之积；对任意 $\mathbf b$，$A\mathbf x=\mathbf b$ 有唯一解；$A^T$ 可逆 |

## 5. 初等矩阵与 LU 分解

| 结论 | 内容 |
| --- | --- |
| 初等矩阵 | 单位矩阵经一次初等行变换所得，**必可逆** |
| 左乘 / 右乘 | $EA$ 相当于行变换；$AE$ 相当于列变换 |
| 三种初等行变换 | 交换两行；某行乘非零常数；某行加另一行的若干倍（均不改变方程组解集） |
| 可逆性保持 | 两个可逆矩阵之积仍可逆；$A$ 可逆 $\Rightarrow EA$ 可逆 |
| 零列保持 | $E\mathbf 0=\mathbf 0$，左乘初等矩阵一定保留原有的零列 |
| 零行不保持 | 行变换可使零行变成非零行 |
| LU 分解 | $A=LU$，$L$ 下三角（主对角线上方全 0）、$U$ 上三角（主对角线下方全 0）；需行交换时写成 $PA=LU$（$P$ 置换矩阵） |
| 左乘与 LU | 行交换可能破坏普通 $A=LU$ 形式，故"有 LU 分解"不一定被保持 |
| 用途 | $A=LU$ 时先解 $Ly=b$，再解 $Ux=y$；也用于求行列式与逆矩阵 |
| ※ Cholesky 分解 | 实对称正定矩阵可唯一写成 $A=LL^T$（$L$ 下三角且对角元为正） |
| ※ QR 分解 | $A=QR$，$Q$ 列正交、$R$ 上三角；由 Gram-Schmidt 得到，用于最小二乘 |

## 6. 线性方程组

| 结论 | 条件 |
| --- | --- |
| 矩阵形式 | $A\mathbf x=\mathbf b$；系数矩阵 $A$、常数列 $\mathbf b$、增广矩阵 $[A\mid\mathbf b]$ |
| 无解 | $\operatorname{rank}(A)<\operatorname{rank}([A\mid\mathbf b])$（出现矛盾行） |
| 唯一解 | $\operatorname{rank}(A)=\operatorname{rank}([A\mid\mathbf b])=n$，无自由变量 |
| 无穷多解 | $\operatorname{rank}(A)=\operatorname{rank}([A\mid\mathbf b])<n$ |
| 自由变量个数 | $n-\operatorname{rank}(A)$ = 未知数个数 − 主元个数（**不能**用"未知数 − 方程数"） |
| 自由变量 | 无主元的列对应的变量；不一定是最后一个变量 |
| 齐次方程组 | $A\mathbf x=\mathbf 0$ 有非零解 $\iff\det(A)=0\iff\operatorname{rank}(A)<n$ |
| 2×2 快速判定 | $\Delta=ad-bc\neq0$ → 唯一解；$\Delta=0$ 时再看增广矩阵是否出现矛盾行，分别对应无穷多解 / 无解 |
| ※ 2×2 比例判据 | $\Delta=0$ 且系数与常数项成同一比例 → 无穷多解；$\Delta=0$ 但常数项不成比例 → 无解 |
| 高斯消元 | 增广矩阵 → 行阶梯形 → 定位主元列 → 区分基本变量与自由变量 |
| ※ 解的结构 | 非齐次通解 = 对应齐次通解 + 一个特解；齐次解空间维数 = $n-\operatorname{rank}(A)$ |
| ※ 克拉默法则 | $\det(A)\neq0$ 时 $x_j=\det(A_j)/\det(A)$，$A_j$ 为把 $A$ 第 $j$ 列换成 $\mathbf b$ 所得矩阵 |
| ※ 最小二乘 | $A\mathbf x=\mathbf b$ 无解时，最优近似解满足正规方程 $A^TA\mathbf x=A^T\mathbf b$ |
| 常见错误 | 记错 $\Delta=ad-bc$ 的符号；只判断 $\Delta\neq0$ 的分支；漏掉 $\Delta=0$ 的一致性检查 |

## 7. 向量、内积与向量空间

| 结论                     | 内容                                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 线性组合                   | 判断 $\mathbf b$ 是否可由 $\mathbf v_1,\dots,\mathbf v_k$ 表示 ⇔ 解对应线性方程组是否相容                                                                                                    |
| 线性相关                   | 存在不全为 0 的系数使 $\sum a_i\mathbf v_i=\mathbf 0$；两向量相关 $\iff$ 成比例；含零向量必相关；有相同向量或成比例向量必相关                                                                                     |
| 线性无关                   | 方程只有全零解                                                                                                                                                                  |
| 生成集 / 张成               | $\operatorname{Span}\{\mathbf v_1,\dots\}$；$n$ 个 $n$ 维向量生成 $\mathbb R^n\iff\det\neq0\iff\operatorname{rank}=n\iff$ 线性无关                                                  |
| 基（Basis）               | 线性无关 + 张成整个空间；标准基 $e_1,\dots,e_n$，$\mathbf x=\sum_i x_i e_i$                                                                                                             |
| 子空间维度                  | $\dim(V)=n-$（独立线性约束数）$=n-\operatorname{rank}(A)$                                                                                                                         |
| 正交                     | $\mathbf u\perp\mathbf v\iff\mathbf u\cdot\mathbf v=0$（逐分量乘积求和，勿漏分量）                                                                                                     |
| ※ 范数与单位向量              | $\Vert\mathbf v\Vert=\sqrt{\mathbf v\cdot\mathbf v}$；$\Vert\mathbf v\Vert=1$ 为单位向量；$\Vert c\mathbf v\Vert=\lvert c\vert\Vert\mathbf v\Vert$                              |
| ※ Cauchy-Schwarz       | $\lvert\mathbf u\cdot\mathbf v\rvert\leq\Vert\mathbf u\Vert\,\Vert\mathbf v\Vert$，等号 $\iff$ 两向量线性相关                                                                      |
| ※ 三角不等式                | $\Vert\mathbf u+\mathbf v\Vert\leq\Vert\mathbf u\Vert+\Vert\mathbf v\Vert$                                                                                               |
| ※ 夹角                   | $\cos\theta=\dfrac{\mathbf u\cdot\mathbf v}{\Vert\mathbf u\Vert\,\Vert\mathbf v\Vert}$                                                                                   |
| ※ 投影                   | $\operatorname{proj}_{\mathbf u}\mathbf v=\dfrac{\mathbf u\cdot\mathbf v}{\mathbf u\cdot\mathbf u}\,\mathbf u$；垂直分量 $\mathbf v-\operatorname{proj}_{\mathbf u}\mathbf v$ |
| ※ 规范正交基 / Gram-Schmidt | 基向量两两正交且均为单位向量；$\mathbf u_k=\mathbf v_k-\sum_{j<k}\operatorname{proj}_{\mathbf u_j}\mathbf v_k$，再逐单位化                                                                    |
| ※ 线性相关判定速查             | 向量个数 > 维度必相关；含零向量必相关；两向量成比例必相关；$n$ 个 $n$ 维向量无关 $\iff$ 拼成矩阵 $\det\neq0$                                                                                                   |
| ※ 行列式判生成               | $n$ 个 $n$ 维向量生成全空间 $\iff\operatorname{rank}=n\iff\det\neq0\iff\lvert\det\rvert>0$（平行六面体体积非零）                                                                             |
| 常见错误                   | 只看一个分量就判线性相关；把"向量个数"当成"线性无关向量个数"；直接说维度是 1 或 $n$                                                                                                                          |

## 8. 线性变换

| 结论 | 公式 / 方法 |
| --- | --- |
| 定义 | $T(a\mathbf u+b\mathbf v)=aT(\mathbf u)+bT(\mathbf v)$（加法性 + 齐次性，须同时满足） |
| 必要条件 | $T(\mathbf 0)=\mathbf 0$（只是必要非充分）；含非零常数项的映射不是线性变换 |
| 矩阵表示 | $T(\mathbf x)=A\mathbf x$，$A=[T(e_1)\ \cdots\ T(e_n)]$，第 $j$ 列就是 $T(e_j)$ |
| 求未知的 $T(e_j)$ | 把已知输入向量拆成标准基线性组合 → 用线性性展开 → 代入已知像 → 移项求解 |
| ※ 核与像 | $\ker(T)=\{\mathbf v:T\mathbf v=\mathbf 0\}$、$\operatorname{Im}(T)=\{T\mathbf v\}$；都是子空间 |
| ※ 秩-零化度 | $\dim\ker(T)+\dim\operatorname{Im}(T)=\dim(\text{定义域})$ |
| ※ 单射 / 满射 / 同构 | 单射 $\iff\ker(T)=\{\mathbf 0\}$；满射 $\iff\operatorname{Im}(T)$ 等于到达空间；两者兼具为同构 |
| ※ 复合与基变换 | 变换复合对应矩阵乘积（作用顺序从右到左）；同一变换在不同基下的矩阵相似：$B=P^{-1}AP$ |
| ※ 常见线性变换 | 旋转、反射、伸缩、投影都是线性变换；平移不是线性变换（除非平移量为 0） |

## 9. 特征值与特征向量

| 结论 | 公式 / 性质 |
| --- | --- |
| 定义 | $A\mathbf v=\lambda\mathbf v$，其中 $\mathbf v\neq\mathbf 0$（零向量永远不是特征向量） |
| 特征方程 | $\det(A-\lambda I)=0$；$n$ 阶方阵在复数域恰有 $n$ 个特征值（含重根） |
| 特征向量求法 | 对每个 $\lambda_i$，解齐次方程组 $(A-\lambda_i I)\mathbf v=\mathbf 0$，其非零解即特征向量 |
| 矩阵多项式 | $p(A)\mathbf v=p(\lambda)\mathbf v$；$A^k\to\lambda^k$、$A+kI\to\lambda+k$、$kA\to k\lambda$、$A^2+I\to\lambda^2+1$（特征向量不变） |
| 行和技巧 | 每行元素和均为 $c\Rightarrow A\mathbf 1=c\mathbf 1$，故 $c$ **必是**特征值，$\mathbf 1=(1,\dots,1)^T$ 是对应特征向量 |
| 列和技巧 | 每列元素和为 $c\Rightarrow\mathbf 1^T A=c\mathbf 1^T$（左特征向量），$c$ 同样是特征值 |
| 求逆与幂 | $\lambda\neq0$ 时 $A^{-1}$ 的特征值为 $1/\lambda$；$A^k$ 的特征值为 $\lambda^k$；$A^T$ 与 $A$ 有相同特征值 |
| 做题套路 | 已知矩阵多项式方程 $p(A)=0$ 且常数项非零时，移项并提取 $A$ 因子即可读出 $A^{-1}$（凯莱-哈密顿思想：方阵满足自身特征多项式），不必用伴随矩阵 |
| ※ 迹与行列式 | $\sum_i\lambda_i=\operatorname{tr}(A)$、$\prod_i\lambda_i=\det(A)$；常用于由一个特征值反推另一个 |
| ※ 相似 | $B=P^{-1}AP$ ⇒ $A,B$ 特征值、迹、行列式、秩、特征多项式都相同 |
| ※ 可对角化 | $A=PDP^{-1}$（$D$ 对角阵）$\iff A$ 有 $n$ 个线性无关特征向量；有 $n$ 个互异特征值必可对角化 |
| ※ 重数 | 代数重数（特征根重数）$\geq$ 几何重数（对应特征子空间维数）；可对角化 $\iff$ 每个特征值两者相等 |
| ※ 快速求幂 | 可对角化时 $A^k=PD^kP^{-1}$；对角 / 三角矩阵的特征值即主对角线元素 |
| ※ 实对称矩阵 | 谱分解 $A=Q\Lambda Q^T$（$Q$ 正交）；特征值全实；不同特征值的特征向量正交 |
| ※ 正定 / 半正定 | 对称矩阵正定 $\iff$ 全部特征值 $>0\iff$ 各阶顺序主子式 $>0\iff\mathbf x^TA\mathbf x>0\ (\forall\mathbf x\neq\mathbf 0)$；半正定把 $>$ 换成 $\geq$；正定必可逆 |
| ※ 二次型 | $\mathbf x^TA\mathbf x$（$A$ 取对称部分）；经正交变换化为标准形 $\sum\lambda_i y_i^2$；正 / 负惯性指数 = 正 / 负特征值个数 |
| ※ 瑞利商 | 实对称矩阵满足 $\lambda_{\min}\leq\dfrac{\mathbf x^TA\mathbf x}{\mathbf x^T\mathbf x}\leq\lambda_{\max}$ |
| 常见错误 | 以为必须知道矩阵具体元素才能求特征值；求 $p(A)$ 的特征值时重新解特征方程；把 $(0,0,0)^T$ 当特征向量 |

## 11. 高频易错点速查

| 陷阱                                                | 正确结论                                                |
| ------------------------------------------------- | --------------------------------------------------- |
| 用伴随矩阵硬算 $A^{-1}$                                  | 有矩阵多项式等式时，移项提取 $A$ 因子直接读出 $A^{-1}$                  |
| 以为矩阵乘法不满足结合律                                      | 只要定义良好，结合律恒成立；不满足的是交换律                              |
| $\det(A-B)=\det(A)-\det(B)$                       | 行列式对加减法没有分配律；数乘才是 $\det(kA)=k^n\det(A)$             |
| 子空间维度答 1 或 $n$                                    | 维度 = $n-$ 独立线性约束数                                   |
| 以为方阵之间一定能相乘                                       | 只看"左列数 = 右行数"，且先检查 $BA$ 是否有定义                       |
| 行列式展开时符号出错                                        | 用 $C_{ij}=(-1)^{i+j}M_{ij}$ 的棋盘符号                   |
| 只用"未知数 − 方程数"求自由变量                                | 必须用 $n-\operatorname{rank}(A)$，方程可能线性相关             |
| 判断独立只看一个分量                                        | 必须整体成比例或解 $\sum a_i\mathbf v_i=\mathbf 0$           |
| 条件不足时强行断言"可逆 / 有 LU 分解 / 有零行"                     | 可逆性与零列被初等左乘保持；LU 分解与零行不一定保持                         |
