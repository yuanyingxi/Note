## 1. 计数原理

| 结论 | 公式 |
| --- | --- |
| 加法原理 | 互斥的几类方式：$m+n$ |
| 乘法原理 | 分步依次完成：$m\times n$ |
| 阶乘 | $n!=n(n-1)\cdots 2\cdot1$，$0!=1$ |
| 排列（考虑顺序） | $P(n,r)=\dfrac{n!}{(n-r)!}$ |
| 组合（不考虑顺序） | $C(n,r)=\binom nr=\dfrac{n!}{r!(n-r)!}$ |
| 组合恒等式 | $\binom nr=\binom n{n-r}$、$\binom nr=\binom{n-1}{r-1}+\binom{n-1}r$、$\sum_r\binom nr=2^n$ |
| 二项式定理 | $(a+b)^n=\sum_{k=0}^n\binom nk a^kb^{n-k}$ |
| 多项式系数 | $n$ 个不同对象分给 $k$ 个**有区别**的组，各组大小 $r_i$：$N=\dfrac{n!}{r_1!r_2!\cdots r_k!}$；等大小 $r$ 时 $N=\dfrac{n!}{(r!)^k}$ |
| 组无区别 | 若 $k$ 个大小相同的组彼此不可区分，需再除以 $k!$ |
| ※ 可重复组合 | 从 $n$ 类中可重复选 $r$ 个（不计顺序）：$\binom{n+r-1}{r}$ |
| ※ 圆排列 / 有重复元素排列 | $n$ 个不同对象围成一圈：$(n-1)!$；含重复元素的排列：$\dfrac{n!}{n_1!\cdots n_k!}$ |
| 套路 | 先判"有序 / 无序"，再判"接收者是否有区别"，最后除去组内顺序重复 |

## 2. 概率公理、事件运算与条件概率

| 结论 | 公式 / 判据 |
| --- | --- |
| ※ 概率公理 | $0\leq P(A)\leq1$；$P(\Omega)=1$；互斥事件可数可加 $P(\bigcup_i A_i)=\sum_i P(A_i)$ |
| ※ 加法公式 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$；三事件容斥再加 $P(A\cap B\cap C)$ 项 |
| ※ 德摩根律 | $\overline{A\cup B}=\bar A\cap\bar B$、$\overline{A\cap B}=\bar A\cup\bar B$ |
| ※ 单调性 | $A\subseteq B\Rightarrow P(A)\leq P(B)$；$P(A)\leq1$；$P(\varnothing)=0$ |
| 条件概率 | $P(B\mid A)=\dfrac{P(A\cap B)}{P(A)}$；$P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}$（分母是**条件事件**的概率） |
| 乘法公式 | $P(A\cap B)=P(A)P(B\mid A)$ |
| ※ 链式法则 | $P(A\cap B\cap C)=P(A)\,P(B\mid A)\,P(C\mid A\cap B)$ |
| 独立性 | $A,B$ 独立 $\iff P(A\cap B)=P(A)P(B)$；此时 $P(A\mid B)=P(A)$ |
| 互斥 ≠ 独立 | 互斥是 $P(A\cap B)=0$，一般**不是**独立（除非其中一事件概率为 0） |
| ※ 多个事件独立 | 相互独立要求对任意子集都满足乘法公式；**两两独立 ≠ 相互独立** |
| ※ 条件独立 | $P(A\cap B\mid C)=P(A\mid C)P(B\mid C)$；与无条件独立互不蕴含 |
| ※ 条件概率也是概率 | 固定条件 $B$ 后 $P(\cdot\mid B)$ 满足全部概率公理，可直接使用加法 / 全概率 / 贝叶斯 |
| 全概率公式 | $P(B)=\sum_i P(A_i)P(B\mid A_i)$，其中 $A_i$ 互斥且覆盖全部情况 |
| 贝叶斯公式 | $P(A\mid B)=\dfrac{P(B\mid A)P(A)}{P(B)}=\dfrac{P(B\mid A)P(A)}{P(B\mid A)P(A)+P(B\mid\bar A)P(\bar A)}$ |
| ※ 一般形式 | $P(A_i\mid B)=\dfrac{P(B\mid A_i)P(A_i)}{\sum_j P(B\mid A_j)P(A_j)}$；术语：先验 $P(A_i)$、似然 $P(B\mid A_i)$、证据 $P(B)$、后验 $P(A_i\mid B)$ |
| 补事件 | $P(\bar A)=1-P(A)$；"至少一个"类问题用 $1-P(\text{一个都没有})$ |
| 子集比较套路 | $C\subsetneq B\Rightarrow A\cap C\subseteq A\cap B$ 且 $P(C)<P(B)$；比较 $P(A\mid B)$ 与 $P(A\mid C)$ 时必须展开定义，分别比较分子与分母，不能凭直觉 |
| 判定独立的标准做法 | 枚举样本点计算 $P(A\cap B)$ 与 $P(A)P(B)$；"元素个数少""交集为空"都不能作为独立依据 |

## 3. 随机变量与 PMF / PDF / CDF

| 类型 | 概率函数 | 归一化 | 区间概率 | 单点概率 |
| --- | --- | --- | --- | --- |
| 离散型 | PMF $P(X=x)$ | $\sum_x P(X=x)=1$ | 对概率求和 | 可大于 0 |
| 连续型 | PDF $f(x)\geq0$ | $\int_{-\infty}^{+\infty}f(x)\,dx=1$ | $\int_a^b f(x)\,dx$ | $P(X=a)=0$ |
| 通用 | CDF $F(x)=P(X\leq x)$ | 单调不减，$F(+\infty)=1$ | $P(a<X\leq b)=F(b)-F(a)$ | — |

| 结论 | 公式 / 套路 |
| --- | --- |
| 连续型 CDF | $F(x)=\int_{-\infty}^{x}f(t)\,dt$；若 PDF 连续则 $F'(x)=f(x)$ |
| 求 PDF 中未知常数 | $p(x)=Kf(x)$（$a\leq x\leq b$）时 $K=\dfrac{1}{\int_a^b f(x)\,dx}$，并需满足非负性 |
| 区间概率 | 先把题目区间与 PDF 的有效区间**取交集**再积分 |
| 连续型端点 | $P(a\leq X\leq b)=P(a<X<b)$，端点是否取等不影响结果 |
| PDF 本身不是概率 | 概率是密度曲线下的面积 |
| 关键区分 | $F(x)=P(X\leq x)$ 是累积值；$F(0)\neq P(X=0)$ |
| ※ CDF 性质 | $F(-\infty)=0$、$F(+\infty)=1$、单调不减、右连续；$P(X>a)=1-F(a)$；离散型 $F$ 为阶梯函数，跳高 = 该点 PMF |
| ※ 分位数 | $p$ 分位数 $F^{-1}(p)=\inf\{x:F(x)\geq p\}$；中位数 $F^{-1}(0.5)$ |
| ※ 离散 / 连续对照 | 离散用 PMF、求和、单点概率可非零、常见为二项 / 泊松 / 几何；连续用 PDF、积分、单点概率恒 0、常见为正态 / 均匀 / 指数 |
| ※ 联合与边缘 | $f_X(x)=\int f_{X,Y}(x,y)\,dy$（连续）或 $\sum_y P(X=x,Y=y)$（离散）；条件 $f_{Y\mid X}(y\mid x)=\dfrac{f_{X,Y}(x,y)}{f_X(x)}$ |
| ※ 联合独立判据 | $X,Y$ 独立 $\iff f_{X,Y}(x,y)=f_X(x)f_Y(y)$ 对所有 $x,y$ 成立；等价地 $F_{X,Y}=F_XF_Y$ |
| ※ 随机变量函数的期望 | $E[g(X)]=\sum_x g(x)P(X=x)$ 或 $\int g(x)f(x)\,dx$（无需先求 $g(X)$ 的分布） |
| ※ 线性变量变换 | $Y=aX+b$（$a\neq0$）时 $f_Y(y)=\dfrac{1}{\lvert a\rvert}f_X\!\left(\dfrac{y-b}{a}\right)$ |
| ※ 一般单调变换 | $Y=g(X)$ 且 $g$ 单调可导时 $f_Y(y)=\dfrac{f_X(x)}{\lvert g'(x)\rvert}$（$x=g^{-1}(y)$） |
| ※ 独立和的分布（卷积） | $f_{X+Y}(z)=\int f_X(x)f_Y(z-x)\,dx$；离散型改为求和 |
| 常见错误 | 把 $F(0)$ 写成 $P(X=0)$；忘记对离散分布累加所有 $\leq x$ 的取值 |

## 4. 期望、方差、协方差与不等式

| 结论 | 公式 |
| --- | --- |
| 期望（离散 / 连续） | $E[X]=\sum_i x_ip_i$ / $E[X]=\int_{-\infty}^{+\infty}xp(x)\,dx$ |
| 线性性 | $E[aX+b]=aE[X]+b$；$E[c]=c$；$E[X+Y]=E[X]+E[Y]$（不需要独立） |
| ※ 乘积的期望 | 仅当独立时 $E[XY]=E[X]E[Y]$；一般不成立 |
| 方差定义 | $\operatorname{Var}(X)=E[(X-\mu)^2]=E[(X-E[X])^2]$ |
| 计算式 | $\operatorname{Var}(X)=E[X^2]-(E[X])^2$（平方的期望 − 期望的平方） |
| 常数运算 | $\operatorname{Var}(c)=0$；$\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$ |
| 独立和 | $X,Y$ 独立时 $\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)$ |
| ※ 线性组合方差 | $\operatorname{Var}(aX+bY)=a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y)$；$\operatorname{Var}(X-Y)$ 同样是"相加" |
| 标准差 | $\sigma=\sqrt{\operatorname{Var}(X)}$，量纲与原变量一致 |
| 二阶矩不等式 | $E[X^2]\geq(E[X])^2$，等号 $\iff X$ 几乎处处为常数（方差非负 / Jensen 方向别用反） |
| i.i.d. 之和 | $E[S_n]=n\mu$；$\operatorname{Var}(S_n)=n\sigma^2$；$\operatorname{SD}(S_n)=\sigma\sqrt n$；样本均值 $E[\bar X]=\mu$、$\operatorname{Var}(\bar X)=\sigma^2/n$ |
| ※ 协方差 | $\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]=E[(X-\mu_X)(Y-\mu_Y)]$；双线性、对称、$\operatorname{Cov}(X,X)=\operatorname{Var}(X)$ |
| ※ 相关系数 | $\rho_{XY}=\dfrac{\operatorname{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1]$；$\lvert\rho\rvert=1\iff$ 存在线性关系 |
| ※ 独立 vs 不相关 | 独立 $\Rightarrow\operatorname{Cov}=0$（不相关），反之不成立；**多元正态**情形下不相关 $\iff$ 独立 |
| ※ 协方差矩阵 | $\Sigma=E[(\mathbf X-\boldsymbol\mu)(\mathbf X-\boldsymbol\mu)^T]$，对称半正定；对角元为各方差，非对角元为协方差 |
| ※ 矩 | $k$ 阶原点矩 $E[X^k]$、$k$ 阶中心矩 $E[(X-\mu)^k]$；偏度 $\gamma_1=E[(X-\mu)^3]/\sigma^3$、峰度 $\gamma_2=E[(X-\mu)^4]/\sigma^4-3$ |
| ※ 马尔可夫不等式 | $X\geq0,\ a>0$ 时 $P(X\geq a)\leq\dfrac{E[X]}{a}$ |
| ※ 切比雪夫不等式 | $P(\lvert X-\mu\rvert\geq k\sigma)\leq\dfrac{1}{k^2}$；对任意有有限方差的分布成立，是**上界**不是等式 |
| ※ Jensen 不等式 | $\varphi$ 凸时 $E[\varphi(X)]\geq\varphi(E[X])$；凹函数反向；$E[X^2]\geq(E[X])^2$ 是 $\varphi(x)=x^2$ 的特例 |
| ※ 条件期望 | $E[X\mid Y=y]=\sum_x xP(X=x\mid Y=y)$；$E[X\mid Y]$ 本身是随机变量 |
| ※ 全期望 / 全方差公式 | $E[X]=E[E[X\mid Y]]$；$\operatorname{Var}(X)=E[\operatorname{Var}(X\mid Y)]+\operatorname{Var}(E[X\mid Y])$ |
| 常见错误 | 混淆 $E[X^2]$ 与 $(E[X])^2$；把方差与标准差混淆；把 Jensen 方向用反 |

## 5. 常见概率分布对比（核心速查表）
### 5.1 离散型

| 分布 | 英文 | 主要用途 | 取值 | 均值 | 方差 |
| --- | --- | --- | --- | --- | --- |
| 伯努利分布 | Bernoulli | 单次成功或失败 | $0,1$ | $p$ | $p(1-p)$ |
| 二项分布 | Binomial | 固定次数的成功次数 | $0,\ldots,n$ | $np$ | $np(1-p)$ |
| 几何分布 | Geometric | 第一次成功所需次数 | $1,2,\ldots$ | $\frac1p$ | $\frac{1-p}{p^2}$ |
| 泊松分布 | Poisson | 固定区间内的事件次数 | $0,1,2,\ldots$ | $\lambda$ | $\lambda$ |
| 离散均匀分布 | Discrete Uniform | 有限个等可能结果 | 指定离散集合 | 依取值而定 | 依取值而定 |
| 超几何分布 | Hypergeometric | 不放回抽样的成功次数 | 有限整数集合 | $n\frac KN$ | $n\frac KN\left(1-\frac KN\right)\frac{N-n}{N-1}$ |
| 负二项分布 | Negative Binomial | 第 $n$ 次成功时的总试验次数 | $n,n+1,\ldots$ | $\frac np$ | $\frac{n(1-p)}{p^2}$ |
| ※ 多项分布 | Multinomial | 多类别计数的联合分布 | $\sum k_i=n$ | $np_i$ | $np_i(1-p_i)$（单个分量） |

### 5.2 连续型

| 分布 | 英文 | 主要用途 | 取值 | 均值 | 方差 |
| --- | --- | --- | --- | --- | --- |
| 均匀分布 | Uniform | 区间内密度相同 | $[a,b]$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| 正态分布 | Normal | 对称钟形数据 | $(-\infty,+\infty)$ | $\mu$ | $\sigma^2$ |
| 指数分布 | Exponential | 事件等待时间 | $[0,+\infty)$ | $\frac1\lambda$ | $\frac1{\lambda^2}$ |
| ※ 卡方分布 | Chi-squared | 标准正态平方和、方差检验 | $[0,+\infty)$ | $n$ | $2n$ |
| ※ t 分布 | Student's t | 小样本均值检验 | $(-\infty,+\infty)$ | $0\ (n>1)$ | $\frac{n}{n-2}\ (n>2)$ |
| ※ 伽马分布 | Gamma | 第 $n$ 次事件的等待时间 | $[0,+\infty)$ | $\frac{\alpha}{\lambda}$ | $\frac{\alpha}{\lambda^2}$ |

### 5.3 分布选择关键词

| 题目关键词                | 优先考虑的分布 |
| -------------------- | ------- |
| 一次试验、成功或失败           | 伯努利分布   |
| 固定 $n$ 次试验、统计成功次数    | 二项分布    |
| 直到第一次成功              | 几何分布    |
| 固定时间 / 区间内发生多少次事件    | 泊松分布    |
| 不放回抽取、统计目标数量         | 超几何分布   |
| 区间内所有数值等可能           | 连续均匀分布  |
| 钟形曲线、均值与标准差          | 正态分布    |
| 等待事件发生的时间            | 指数分布    |
| 第 $n$ 次成功 / 多个独立几何之和 | 负二项分布   |
| ※ 一次试验有多个互斥类别、统计各类次数 | 多项分布    |
| ※ 标准正态变量平方和          | 卡方分布    |

### 5.4 概率函数与关键性质

| 分布 | PMF / PDF | 关键性质 |
| --- | --- | --- |
| Bernoulli | $p^x(1-p)^{1-x},\ x\in\{0,1\}$ | — |
| Binomial | $\binom nk p^k(1-p)^{n-k}$ | $n$ 大、$p$ 小、$np=\lambda$ 时近似 $\text{Poisson}(\lambda)$ |
| Geometric（试验次数） | $(1-p)^{k-1}p,\ k=1,2,\ldots$ | 无记忆性；$E=1/p$ |
| Geometric（失败次数） | $(1-p)^k p,\ k=0,1,\ldots$ | 同一英文名两种定义：$E=(1-p)/p$，$\operatorname{Var}=(1-p)/p^2$，**做题先看定义** |
| Poisson | $e^{-\lambda}\lambda^k/k!$ | 离散、可取可数无限个值、非负；Mean = Variance = $\lambda$；$\sigma=\sqrt\lambda$ |
| Discrete Uniform | $P(X=x_i)=1/n$ | 取值 $\{1,\ldots,n\}$ 时 $E=(n+1)/2$，$\operatorname{Var}=(n^2-1)/12$ |
| Hypergeometric | $\dfrac{\binom Kk\binom{N-K}{n-k}}{\binom Nn}$ | 与二项的区别：不放回、各次不独立 |
| Negative Binomial | $\binom{k-1}{n-1}p^n(1-p)^{k-n}$ | $n$ 个独立同分布几何（从 1 起）之和 |
| Uniform | $\frac1{b-a}$ on $[a,b]$ | $P(c\leq X\leq d)=\frac{d-c}{b-a}$ |
| Normal | $\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $N(\mu,\sigma^2)$ 第二个参数是**方差**不是标准差 |
| Exponential | $\lambda e^{-\lambda x},\ x\geq0$ | 无记忆性 $P(X>s+t\mid X>s)=P(X>t)$；$\lambda$ 是速率不是均值 |
| ※ Multinomial | $\dfrac{n!}{k_1!\cdots k_m!}p_1^{k_1}\cdots p_m^{k_m}$ | $\operatorname{Cov}(X_i,X_j)=-np_ip_j$；边缘分布为 $\text{Binomial}(n,p_i)$ |
| ※ Chi-squared | $\sum_{i=1}^n Z_i^2\ (Z_i\sim N(0,1)$ 独立$)$ | 可加性：独立卡方之和仍为卡方，自由度相加 |
| ※ Gamma | $\dfrac{\lambda^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\lambda x}$ | $\alpha=1$ 退化为指数分布；整数 $\alpha$ 为第 $\alpha$ 次事件的等待时间 |

### 5.5 分布之间的关系与可加性

| 结论 | 内容 |
| --- | --- |
| 几何分布求和 | $n$ 个 i.i.d. 几何（从 1 起）之和 $\sim NB(n,p)$，$E=n/p$，$\operatorname{Var}=n(1-p)/p^2$；若按"失败次数"定义，则和为"第 $n$ 次成功前的失败次数"，$E=n(1-p)/p$，$\operatorname{Var}=n(1-p)/p^2$ |
| 泊松近似二项 | $n\to\infty$、$p\to0$、$np=\lambda$ 固定时 $\text{Binomial}(n,p)\to\text{Poisson}(\lambda)$ |
| 二项近似超几何 | 总体 $N$ 很大、抽样量 $n$ 很小时，超几何近似 $\text{Binomial}(n,K/N)$ |
| ※ 二项可加 | $X_i\sim\text{Binomial}(n_i,p)$ 独立同 $p$ ⇒ $\sum_i X_i\sim\text{Binomial}(\sum_i n_i,p)$ |
| ※ 泊松可加 | 独立 $X_i\sim\text{Poisson}(\lambda_i)$ ⇒ $\sum_i X_i\sim\text{Poisson}(\sum_i\lambda_i)$ |
| ※ 正态可加 | 独立正态的线性组合仍正态：$aX+bY\sim N(a\mu_X+b\mu_Y,\ a^2\sigma_X^2+b^2\sigma_Y^2)$ |
| ※ 指数与泊松过程 | 速率 $\lambda$ 的泊松过程中，事件间隔 $\sim\text{Exponential}(\lambda)$；第 $n$ 次事件等待时间 $\sim\text{Gamma}(n,\lambda)$；$n$ 个独立 $\text{Exp}(\lambda)$ 的最小值 $\sim\text{Exp}(n\lambda)$ |
| ※ 正态近似二项 | $np$ 与 $n(1-p)$ 都较大时用 $N(np,\ np(1-p))$ 近似，配合连续性修正 |
| ※ 正态近似泊松 | $\lambda$ 较大时用 $N(\lambda,\lambda)$ 近似 |
| ※ 卡方与正态 | $Z\sim N(0,1)\Rightarrow Z^2\sim\chi^2(1)$；样本方差经标准化后与卡方相关 |
| 常见错误 | 把几何分布写成二项分布；把负二项写成二项分布；把泊松当连续型分布 |

## 6. 正态分布与标准化

| 结论 | 公式 |
| --- | --- |
| 标准化 | $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$；$E[Z]=0$，$\operatorname{Var}(Z)=1$ |
| 一般概率换算 | $P(X\leq x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$；$P(a<X<b)=\Phi\!\left(\dfrac{b-\mu}{\sigma}\right)-\Phi\!\left(\dfrac{a-\mu}{\sigma}\right)$ |
| 对称性 | $Z\sim N(0,1)\Rightarrow -Z\sim N(0,1)$；$\Phi(-x)=1-\Phi(x)$；$P(X\leq -t)=P(X\geq t)=\dfrac{1-P(-t\leq X\leq t)}{2}$ |
| 区间概率 | $P(-a<X<a)=2\Phi(a)-1$（不是均匀分布，也不能写成任何简单有理式） |
| 68-95-99.7 | $P(\mu\pm\sigma)\approx68\%$，$P(\mu\pm2\sigma)\approx95\%$，$P(\mu\pm3\sigma)\approx99.7\%$ |
| 一般性质 | 关于 $\mu$ 对称；均值 = 中位数 = 众数；$\mu$ 定位置、$\sigma$ 定分散；独立正态之和仍为正态 |
| ※ 线性变换 | $aX+b\sim N(a\mu+b,\ a^2\sigma^2)$；标准化是 $a=1/\sigma,\ b=-\mu/\sigma$ 的特例 |
| ※ 多元正态 | 任意线性组合仍为正态；协方差为 0（不相关）$\iff$ 独立；边缘分布与条件分布仍为正态 |
| ※ 正态与矩 | 奇阶中心矩为 0；$E[(X-\mu)^4]=3\sigma^4$（峰度 0） |
| 常见错误 | 以为对称中心在 $-1$；把正态当均匀分布；把切比雪夫下界当成正态等式；把 $\sigma$ 当 $N(\mu,\sigma^2)$ 的第二参数 |

## 7. 大数定律与中心极限定理

| 结论 | 公式 |
| --- | --- |
| ※ 依概率收敛 | $X_n\xrightarrow{P}c\iff\lim_{n\to\infty}P(\lvert X_n-c\rvert\geq\varepsilon)=0$ |
| ※ 弱 / 强大数定律 | i.i.d. 且 $E[X_i]=\mu$ 时 $\bar X_n\xrightarrow{P}\mu$（弱）；几乎必然收敛 $\bar X_n\xrightarrow{a.s.}\mu$（强） |
| CLT | $X_i$ 独立同分布、$E[X_i]=\mu$、$\operatorname{Var}(X_i)=\sigma^2\in(0,\infty)$ 时 $\dfrac{\sum_{i=1}^n X_i-n\mu}{\sigma\sqrt n}\xrightarrow{d}N(0,1)$ |
| 等价写法 | $\bar X_n\ \dot\sim\ N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$（$n$ 大时近似） |
| 要点 | 原始分布不必是正态，只需有限均值与方差；"均值为 0、方差为 1"不等于服从标准正态；有限 $n$ 只是近似 |
| 识别套路 | 见到"独立同分布 + 均值 $\mu$ + 方差 $\sigma^2$ + $n\to\infty$ + 分子减 $n\mu$、分母 $\sigma\sqrt n$"即 CLT |
| 与标准正态区分 | 标准正态是一个具体分布；CLT 是说明"和经标准化后趋近它"的定理 |
| ※ 与 LLN 分工 | LLN 说明样本均值收敛到常数 $\mu$（一阶）；CLT 说明波动量级为 $\sigma/\sqrt n$ 且分布趋近正态（二阶） |
| ※ 近似计算套路 | 求和 / 平均值的概率 → 先算 $E[S_n]=n\mu$、$\operatorname{SD}(S_n)=\sigma\sqrt n$ → 标准化 → 查 $\Phi$ |

## 8. 特殊题型套路

| 场景 | 套路 |
| --- | --- |
| 素数计数 | 素数定理 $\pi(n)\approx n/\ln n$；随机取到素数的概率 $\approx 1/\ln n$ |
| 古典概型（掷骰等） | 分母按有序对计数（两骰共 36 种），枚举满足条件的有序组合再求和 |
| 两颗骰子的点数和 | 分母固定为 $6\times6=36$ 个**有序**对；只数无序组合（如把 $(a,b)$ 与 $(b,a)$ 合并）会漏掉一半情况，是该题最常见的失分点 |
| 几何概型 + 判别式 | 参数在均匀区间内取值 → 由条件（二次方程有实根即判别式 $\Delta=b^2-4ac\geq0$）解出可行区间 → 用**长度比**求概率 |
| 条件概率与子集比较 | 一律展开 $P(A\mid B)=P(A\cap B)/P(B)$，用集合包含关系比较分子分母 |
| 判定独立性 | 检验 $P(A\cap B)=P(A)P(B)$，不要用"元素少""互斥"代替 |
| ※ 几何概型一般式 | 概率 = 有利区域的测度（长度 / 面积 / 体积）÷ 样本空间总测度；均匀分布是关键前提 |
| ※ 抽球 / 抽样模型 | 有放回 → 各次独立、用二项；不放回 → 用超几何或组合计数；先判"是否放回" |
| ※ 贝叶斯题套路 | 定义划分事件 → 写先验与似然 → 全概率算证据 → 贝叶斯得后验；"已知结果反推来源"即用贝叶斯 |
| ※ "至少一个"类 | 用对立事件 $1-P(\text{全不发生})$；多个事件用容斥原理 |
| ※ 参数含于分布 | 用归一化（PMF 求和为 1 / PDF 积分为 1）或已知概率值反解未知常数 |

## 9. 笔试速查表（指南 3.3 概率部分）

| 项 | 公式 |
| --- | --- |
| 期望 | $E(aX+b)=aE(X)+b$ |
| 方差 | $\operatorname{Var}(X)=E(X^2)-[E(X)]^2$ |

| 二项分布 | $E(X)=np$，$\operatorname{Var}(X)=np(1-p)$ |

## 10. 高频易错点速查

| 陷阱                                                                      | 正确结论                                                  |
| ----------------------------------------------------------------------- | ----------------------------------------------------- |
| $F(0)=P(X=0)$                                                           | $F(x)=P(X\leq x)$，离散型需累加所有 $\leq x$ 的概率               |
| "相互独立"看漏就说无法求                                                           | 独立 $\Rightarrow P(A\cap B)=P(A)P(B)$                  |
| 把互斥当成独立                                                                 | 互斥 $P(A\cap B)=0$，一般不满足乘法公式                           |
| 掷到首次成功写成二项分布                                                            | 等待首次成功是几何分布 $P(X=k)=(1-p)^{k-1}p$                     |
| 多个独立几何之和选二项分布                                                           | 是负二项分布 $NB(n,p)$                                      |
| 几何分布两种定义混用                                                              | 从 1 起（试验次数）$E=1/p$；从 0 起（失败次数）$E=(1-p)/p$             |
| 条件概率分母写错                                                                | 分母是条件事件的概率；子集比较时分子分母都会变                               |
| 正态分布概率当成均匀                                                              | $P(-a<X<a)=2\Phi(a)-1$，用对称性拆区间                        |
| $E[X^2]<(E[X])^2$                                                       | 恒有 $E[X^2]\geq(E[X])^2$（Jensen / 方差非负）                |
| 判别式写成 $\alpha^2-1\geq0$                                                 | 二次方程 $x^2+\alpha x+1=0$ 的判别式是 $\alpha^2-4$            |
| ※ $P(A\cup B)=P(A)+P(B)$                                                | 必须减去 $P(A\cap B)$，除非互斥                                |
| ※ $E[XY]=E[X]E[Y]$                                                      | 需要独立性；一般 $\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]$     |
| ※ $\operatorname{Var}(X-Y)=\operatorname{Var}(X)-\operatorname{Var}(Y)$ | 独立时仍是相加：$\operatorname{Var}(X)+\operatorname{Var}(Y)$ |
| ※ 两两独立即相互独立                                                             | 相互独立需对任意子集都满足乘法公式，条件更强                                |
| ※ 不相关即独立                                                                | 只有多元正态情形下等价；一般独立 ⇒ 不相关，反之不然                           |
| ※ $N(\mu,\sigma)$ 记号                                                    | 标准记法 $N(\mu,\sigma^2)$ 第二参数是方差，标准差是 $\sigma$          |
| ※ 切比雪夫给出精确概率                                                            | 只给出上界 $1/k^2$，不是等式                                    |
