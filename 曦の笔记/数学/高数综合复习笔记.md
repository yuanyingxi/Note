## 1. 函数与映射

| 结论 | 内容 |
| --- | --- |
| 函数定义 | $f:A\to B$，每个输入有且仅有一个输出；不同输入可对应同一输出 |
| 定义域 / 陪域 / 值域 | Domain：允许输入；Codomain：预先指定的目标集合；Range = Image：$f(A)=\{f(x)\mid x\in A\}$ |
| 恒成立 | $f(A)\subseteq B$（任意函数）；$f(A)=B\iff$ 满射 |
| 单射（Injective / one-to-one） | $f(x_1)=f(x_2)\Rightarrow x_1=x_2$ |
| 满射（Surjective / onto） | $\forall y\in B,\ \exists x\in A:\ f(x)=y\iff f(A)=B$ |
| 双射（Bijective） | 单射 + 满射；双射存在反函数 $f^{-1}$ |
| 复合 | $(f\circ g)(x)=f(g(x))$，从最右向左逐层代入；$(f\circ g\circ h)(x)=f(g(h(x)))$；一般不可交换；$\circ$ 不是乘法 |
| 复合定义域 | 逐层检查：每层输出必须落在下一层函数的定义域内，不能只看最外层 |
| 定义域限制 | 分母 $\neq0$；偶次根号内 $\geq0$；$\ln$ 真数 $>0$；$\arcsin$ / $\arccos$ 的自变量在 $[-1,1]$ |
| 值域套路 | 闭区间上连续函数：候选点 = 两端点 + 区间内临界点，取 min 与 max；不能只算端点 |
| 绝对值 | $\lvert x\rvert=x\ (x\geq0)$，$-x\ (x<0)$；内部恒非负时可直接去掉绝对值 |
| 完全平方 | $(a-b)^2=a^2-2ab+b^2$；配方用于化简根号内表达式 |
| ※ 反函数 | 只有双射有反函数；$f^{-1}$ 的定义域 = $f$ 的值域；图像关于 $y=x$ 对称；$(f^{-1})'(y)=\dfrac{1}{f'(x)}$ |
| ※ 奇偶性 | 偶函数 $f(-x)=f(x)$ 关于 $y$ 轴对称；奇函数 $f(-x)=-f(x)$ 关于原点对称且 $f(0)=0$ |
| ※ 周期性 | $f(x+T)=f(x)$；周期函数在任一整周期上的积分相同 |
| ※ 单调 / 有界 | 闭区间上连续必一致连续、必有界、必取到最大最小值（Weierstrass） |
| ※ 介值 / 零点定理 | 连续且 $f(a)f(b)<0$ ⇒ 存在零点；介值定理用于证明方程有解 |

## 2. 极限与连续

| 结论 | 公式 / 判据 |
| --- | --- |
| 连续三条件 | $f(a)$ 有定义 + $\lim_{x\to a}f(x)$ 存在 + $\lim_{x\to a}f(x)=f(a)$，缺一即不连续 |
| 分段点 | 必须分别算左、右极限；左右相等才有双侧极限 |
| 有界 × 趋零 | $f$ 在 $a$ 附近有界、$h\to0\Rightarrow\lim_{x\to a}f(x)h(x)=0$ |
| 夹逼定理 | $u\leq f\leq v$ 且 $\lim u=\lim v=L\Rightarrow\lim f=L$ |
| 常用有界性 | $-1\leq\sin x,\cos x\leq1$；$0\leq\sin^2x\leq1$；指数函数在指数有界时也有界 |
| 未定式 | $0/0$、$\infty/\infty$ 用洛必达 $\lim\dfrac fg=\lim\dfrac{f'}{g'}$，或 Taylor 展开 $e^h=1+h+o(h)$ |
| $0/0$ 不代表 | 既不代表极限不存在，也不代表等于 0 |
| 导数定义 | $f'(x)=\lim_{h\to0}\dfrac{f(x+h)-f(x)}{h}$；代入得 $0/0$ 时不能直接判 undefined |
| 多元极限 | 极限存在 $\Rightarrow$ 任意路径结果相同；两条路径结果不同 $\Rightarrow$ 极限不存在；多条路径相同**不能**证明存在 |
| 多元极限求存在 | 用夹逼；常用不等式 $x^2+y^2\leq(\lvert x\rvert+\lvert y\rvert)^2$，即 $\dfrac{x^2+y^2}{\lvert x\rvert+\lvert y\rvert}\leq\lvert x\rvert+\lvert y\rvert$ |
| 含参数的分式极限 | 分母 $\to0$ 而整体极限有限 $\Rightarrow$ 分子在目标点必须为 0（必要非充分）→ 据此定参数 → 因式分解约分 → 用路径法求其余参数 → 最后验证所有路径 |
| 因式分解套路 | 在分母非 0 的区域内约去公因式，再取极限；目标点无定义不代表极限不存在 |
| ※ 两个重要极限 | $\lim_{x\to0}\dfrac{\sin x}{x}=1$；$\lim_{x\to\infty}\left(1+\dfrac1x\right)^x=e$，等价写法 $\lim_{x\to0}(1+x)^{1/x}=e$ |
| ※ 等价无穷小（$x\to0$） | $\sin x\sim x$、$\tan x\sim x$、$\arcsin x\sim x$、$\arctan x\sim x$、$1-\cos x\sim\frac{x^2}{2}$、$e^x-1\sim x$、$\ln(1+x)\sim x$、$(1+x)^\alpha-1\sim\alpha x$ |
| ※ 有理式极限 | $x\to\infty$ 时抓分子分母最高次项：次数相同 → 系数比；分子次数低 → 0；分子次数高 → $\infty$ |
| ※ 洛必达适用条件 | 仅 $0/0$ 或 $\infty/\infty$，且导数比的极限存在（或为 $\infty$）；可重复使用；不满足条件时不能套用 |
| ※ 其他未定式转化 | $0\cdot\infty$、$\infty-\infty$ 先通分 / 提公因子化为 $0/0$ 或 $\infty/\infty$；$1^\infty$、$0^0$、$\infty^0$ 先取对数（幂指函数写成 $e^{g\ln f}$） |
| ※ 极限运算法则 | 和差积商（分母极限非零）、复合函数极限定理（外层连续时可交换极限与函数） |
| ※ 单调有界准则 | 单调有界数列必收敛；常用于递推数列极限 |
| ※ 间断点分类 | 第一类（可去：左右极限相等但不等于函数值；跳跃：左右极限不等）；第二类（无穷、振荡） |
| ※ 连续函数性质 | 闭区间上连续 ⇒ 有界、取到最值、介值性；初等函数在定义域内连续 |
| 常见错误 | 有界就认为极限存在；分段函数只算右极限；振荡函数直接判极限不存在；忘记检查每层定义域 |

## 3. 导数与微分

| 结论         | 公式                                                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基本导数       | $(x^n)'=nx^{n-1}$、$(e^x)'=e^x$、$(\ln x)'=1/x$、$(\sin x)'=\cos x$、$(\cos x)'=-\sin x$、$(\tan x)'=\sec^2x=1/\cos^2x$                                                                                                  |
| ※ 导数表补充    | $(C)'=0$、$(a^x)'=a^x\ln a$、$(\log_a x)'=\frac{1}{x\ln a}$、$(\arcsin x)'=\frac{1}{\sqrt{1-x^2}}$、$(\arccos x)'=-\frac{1}{\sqrt{1-x^2}}$、$(\arctan x)'=\frac{1}{1+x^2}$、$(\cot x)'=-\csc^2x$、$(\sec x)'=\sec x\tan x$ |
| 链式法则       | $(f(g(x)))'=f'(g(x))\cdot g'(x)$                                                                                                                                                                                    |
| 乘积法则       | $(uv)'=u'v+uv'$                                                                                                                                                                                                     |
| ※ 商法则      | $\left(\dfrac uv\right)'=\dfrac{u'v-uv'}{v^2}$（$v\neq0$）                                                                                                                                                            |
| ※ 高阶导数     | 莱布尼茨公式 $(uv)^{(n)}=\sum_{k=0}^n\binom nk u^{(k)}v^{(n-k)}$；$(e^x)^{(n)}=e^x$、$(\sin x)^{(n)}=\sin(x+\frac{n\pi}{2})$                                                                                                |
| ※ 微分与线性近似  | $dy=f'(x)\,dx$；$f(x+\Delta x)\approx f(x)+f'(x)\Delta x$；可导 $\iff$ 可微（一元）                                                                                                                                           |
| 隐函数求导      | 把 $y$ 看作 $x$ 的函数，两边对 $x$ 求导；凡对 $y$ 求导必乘 $y'$                                                                                                                                                                        |
| 隐函数常用式     | $(y^n)'=ny^{n-1}y'$、$(e^y)'=e^yy'$、$(e^{2y})'=2e^{2y}y'$、$(\ln y)'=y'/y$、$(\sin y)'=\cos y\cdot y'$、$(\cos y)'=-\sin y\cdot y'$                                                                                     |
| 隐函数步骤      | 两边求导 → 含 $y$ 处乘 $y'$ → 收集 $y'$ 项 → 解出 $y'$                                                                                                                                                                          |
| 切线         | 斜率 $m=f'(x_0)$（隐函数时把切点代入 $y'$），点斜式 $y-y_0=m(x-x_0)$；法线斜率 $-1/m$                                                                                                                                                     |
| 偏导         | 对某一变量求导时其余变量视为常数；混合偏导按指定次序逐层求导，每一步都要用乘积 / 链式法则                                                                                                                                                                      |
| 临界点（驻点）    | $f_x=0$ 且 $f_y=0$ 同时成立                                                                                                                                                                                              |
| Taylor 多项式 | $P_n(x)=\sum_{k=0}^{n}\dfrac{f^{(k)}(a)}{k!}(x-a)^k$                                                                                                                                                                |
| 常用低阶       | $P_0=f(a)$；$P_1=f(a)+f'(a)(x-a)$；$P_2=P_1+\dfrac{f''(a)}{2}(x-a)^2$；$P_3=P_2+\dfrac{f'''(a)}{6}(x-a)^3$                                                                                                             |
| Maclaurin  | 展开点 $a=0$ 的 Taylor 多项式                                                                                                                                                                                              |
| Taylor 性质  | $P_n^{(k)}(a)=f^{(k)}(a)$（$k\leq n$）；$f(x)=P_n(x)+R_n(x)$                                                                                                                                                           |
| ※ 拉格朗日余项   | $R_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$；用于估计误差与证明不等式                                                                                                                                                     |
| ※ 中值定理     | Rolle：$f(a)=f(b)$ ⇒ 存在 $\xi$ 使 $f'(\xi)=0$；Lagrange：$f(b)-f(a)=f'(\xi)(b-a)$；Cauchy：$\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$                                                                         |
| ※ 单调与极值    | $f'>0$ 递增、$f'<0$ 递减；一阶导数变号定极值；二阶判别 $f''>0$ 极小、$f''<0$ 极大、$f''=0$ 需另判                                                                                                                                                |
| ※ 凹凸与拐点    | $f''>0$ 凹（下凸）、$f''<0$ 凸（上凸）；$f''$ 变号点为拐点                                                                                                                                                                            |
| ※ 最值套路     | 闭区间上比较端点值、驻点值、不可导点值；开区间结合实际意义与极限判断                                                                                                                                                                                  |
| 常见错误       | 隐函数漏乘 $y'$；二阶项忘除 $2!=2$、三阶忘除 $3!=6$；把 $\circ$ 当乘法                                                                                                                                                                   |

## 4. 积分

| 结论           | 公式                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 牛顿-莱布尼茨      | $\int_a^b f(x)\,dx=F(b)-F(a)$，$F'=f$；定积分不需加 $C$，不定积分需加                                                                                                                                                                                                                                                                                                                                                                                      |
| 微积分基本定理      | $\dfrac{d}{dx}\int_a^x f(t)\,dt=f(x)$                                                                                                                                                                                                                                                                                                                                                                                                       |
| 上限为函数        | $\dfrac{d}{dx}\int_a^{g(x)}f(t)\,dt=f(g(x))g'(x)$（链式法则）                                                                                                                                                                                                                                                                                                                                                                                     |
| 上下限均为函数      | $\dfrac{d}{dx}\int_{u(x)}^{v(x)}f(t)\,dt=f(v(x))v'(x)-f(u(x))u'(x)$                                                                                                                                                                                                                                                                                                                                                                         |
| 分部积分         | $\int u\,dv=uv-\int v\,du$；优先按"对数 / 反三角 → 幂 → 指数 / 三角"选 $u$                                                                                                                                                                                                                                                                                                                                                                                 |
| ※ 第一换元       | $\int f(g(x))g'(x)\,dx=\int f(u)\,du$；凑微分后**定积分须同步换限**                                                                                                                                                                                                                                                                                                                                                                                      |
| ※ 第二换元（三角换元） | $\sqrt{a^2-x^2}\Rightarrow x=a\sin t$；$\sqrt{x^2+a^2}\Rightarrow x=a\tan t$；$\sqrt{x^2-a^2}\Rightarrow x=a\sec t$                                                                                                                                                                                                                                                                                                                           |
| ※ 有理函数       | 先化为多项式 + 真分式，再部分分式分解后逐项积分                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 基本原函数        | $\int 1\,dx=x$、$\int x^n dx=\dfrac{x^{n+1}}{n+1}\ (n\neq-1)$、$\int\frac1x dx=\ln\lvert x\rvert$、$\int\sin x\,dx=-\cos x$、$\int\cos x\,dx=\sin x$、$\int e^x dx=e^x$                                                                                                                                                                                                                                                                          |
| 常用积分         | $\int\ln x\,dx=x\ln x-x+C$；$\int\dfrac{dx}{\sqrt{x^2+a^2}}=\ln\lvert x+\sqrt{x^2+a^2}\rvert+C$；$\int\sec x\,dx=\ln\lvert\sec x+\tan x\rvert+C$                                                                                                                                                                                                                                                                                              |
| ※ 常用积分表补充    | $\int\dfrac{dx}{x^2+a^2}=\frac1a\arctan\frac xa+C$；$\int\dfrac{dx}{\sqrt{a^2-x^2}}=\arcsin\frac xa+C$；$\int\tan x\,dx=\ln\lvert\sec x\rvert+C$；$\int\cot x\,dx=\ln\lvert\sin x\rvert+C$；$\int\sec^2x\,dx=\tan x+C$；$\int a^x dx=\frac{a^x}{\ln a}+C$；$\int e^{ax}dx=\frac1a e^{ax}+C$；$\int\dfrac{dx}{x^2-a^2}=\frac{1}{2a}\ln\left\lvert\frac{x-a}{x+a}\right\rvert+C$；$\int\dfrac{dx}{\sqrt{x^2-a^2}}=\ln\lvert x+\sqrt{x^2-a^2}\rvert+C$ |
| 反常积分收敛       | $\int_0^\infty e^{-ax}dx=\dfrac1a\ (a>0)$                                                                                                                                                                                                                                                                                                                                                                                                   |
| 反常积分发散       | $\int_{-\infty}^0 e^{-ax}dx$（$a>0$）发散到 $+\infty$                                                                                                                                                                                                                                                                                                                                                                                            |
| 反常积分套路       | 先判敛散再算值；写成 $\lim_{t\to\pm\infty}\int_a^t$，指数在 $+\infty$ 端收敛、在 $-\infty$ 端发散                                                                                                                                                                                                                                                                                                                                                                 |
| ※ p-积分判据     | $\int_1^\infty\frac{dx}{x^p}$ 收敛 $\iff p>1$；$\int_0^1\frac{dx}{x^p}$ 收敛 $\iff p<1$                                                                                                                                                                                                                                                                                                                                                          |
| ※ 比较判别       | $0\leq f\leq g$ 且 $\int g$ 收敛 ⇒ $\int f$ 收敛；极限比较看 $\lim f/g$ 是否为有限正数；绝对收敛 ⇒ 收敛                                                                                                                                                                                                                                                                                                                                                              |
| ※ 定积分性质      | 线性性、区间可加、$\int_a^a=0$、$\int_a^b=-\int_b^a$；$[-a,a]$ 上奇函数为 0、偶函数为 $2\int_0^a$                                                                                                                                                                                                                                                                                                                                                                |
| ※ 积分中值定理     | 连续 $f$ 在 $[a,b]$ 上存在 $\xi$ 使 $\int_a^b f(x)\,dx=f(\xi)(b-a)$                                                                                                                                                                                                                                                                                                                                                                                |
| ※ 函数平均值      | $\bar f=\dfrac{1}{b-a}\int_a^b f(x)\,dx$                                                                                                                                                                                                                                                                                                                                                                                                    |
| ※ 奇点处理       | 积分区间内含无界点或使分母为 0 的点时，必须拆成两段反常积分分别判敛，不能直接套牛顿-莱布尼茨                                                                                                                                                                                                                                                                                                                                                                                            |
| 常见错误         | $\int\ln x\,dx$ 漏掉 $-x$；把 $\int 1/\sqrt{x^2+a^2}$ 误记成 arctan 形式；$\int e^{-2x}dx$ 忘除 2；积分限写反                                                                                                                                                                                                                                                                                                                                                 |

## 5. 级数（※ 整节为补充）

| 结论 | 公式 / 判据 |
| --- | --- |
| 收敛定义 | 部分和序列 $S_n$ 有有限极限；$\sum a_n$ 收敛的必要条件是 $a_n\to0$（**不充分**） |
| 几何级数 | $\sum_{n=0}^\infty ar^n$ 收敛 $\iff\lvert r\rvert<1$，和 $=\dfrac{a}{1-r}$ |
| p-级数 | $\sum_{n=1}^\infty\frac{1}{n^p}$ 收敛 $\iff p>1$；调和级数 $p=1$ 发散 |
| 比值判别 | $\lim\left\lvert\frac{a_{n+1}}{a_n}\right\rvert=L<1$ 收敛、$L>1$ 发散、$L=1$ 需另判 |
| 根值判别 | $\lim\sqrt[n]{\lvert a_n\rvert}=L<1$ 收敛、$L>1$ 发散 |
| 积分判别 | $a_n=f(n)$ 且 $f$ 正、连续、递减时，$\sum a_n$ 与 $\int_1^\infty f$ 同敛散 |
| 交错级数 | 莱布尼茨判别：$a_n$ 单调递减且 $a_n\to0$ ⇒ $\sum(-1)^na_n$ 收敛；余项 $\lvert R_n\rvert\leq a_{n+1}$ |
| 绝对 / 条件收敛 | $\sum\lvert a_n\rvert$ 收敛称绝对收敛（必收敛）；$\sum a_n$ 收敛但 $\sum\lvert a_n\rvert$ 发散称条件收敛 |
| 幂级数 | $\sum a_n(x-a)^n$ 收敛半径 $R=\dfrac{1}{\limsup\sqrt[n]{\lvert a_n\rvert}}$；端点收敛性须单独判断 |
| 常用 Maclaurin 展开 | $e^x=\sum\frac{x^n}{n!}$；$\sin x=\sum\frac{(-1)^nx^{2n+1}}{(2n+1)!}$；$\cos x=\sum\frac{(-1)^nx^{2n}}{(2n)!}$；$\ln(1+x)=\sum\frac{(-1)^{n+1}x^n}{n}\ (\lvert x\rvert<1)$；$\frac{1}{1-x}=\sum x^n\ (\lvert x\rvert<1)$；$(1+x)^\alpha=\sum\binom\alpha n x^n$ |
| 常见错误 | 把 $a_n\to0$ 当作收敛的充分条件；忽略端点判敛；对条件收敛级数随意重排 |

## 6. 多元函数微分学（※ 整节为补充）

| 结论            | 公式 / 判据                                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 梯度            | $\nabla f=(f_x,f_y,\dots)$；指向函数增长最快的方向，模长为最大变化率                                                                        |
| 方向导数          | $D_{\mathbf u}f=\nabla f\cdot\mathbf u$，其中 $\mathbf u$ 必须是**单位向量**（未单位化要先归一化）                                          |
| 全微分           | $df=f_x\,dx+f_y\,dy$；偏导连续 ⇒ 可微 ⇒ 连续且偏导存在；偏导存在**不一定**可微                                                                 |
| 多元链式法则        | $\dfrac{df}{dt}=f_x\dfrac{dx}{dt}+f_y\dfrac{dy}{dt}$；$z=f(x(u,v),y(u,v))$ 时对每个自变量分别套链式求和                               |
| 混合偏导相等        | 二阶混合偏导连续时 $f_{xy}=f_{yx}$（Clairaut / Schwarz 定理）                                                                       |
| 隐函数定理         | $F(x,y)=0\Rightarrow\dfrac{dy}{dx}=-\dfrac{F_x}{F_y}$（$F_y\neq0$）；$F(x,y,z)=0\Rightarrow z_x=-\dfrac{F_x}{F_z}$        |
| Hessian 矩阵    | $H=\begin{pmatrix}f_{xx}&f_{xy}\\f_{xy}&f_{yy}\end{pmatrix}$；二阶判别式 $D=f_{xx}f_{yy}-f_{xy}^2$                           |
| 二阶判别          | $D>0$ 且 $f_{xx}>0$ ⇒ 局部极小；$D>0$ 且 $f_{xx}<0$ ⇒ 局部极大；$D<0$ ⇒ 鞍点；$D=0$ ⇒ 判别失效                                            |
| 约束极值          | 拉格朗日乘数法：$\nabla f=\lambda\nabla g$（约束 $g(x,y)=c$），联立求解候选点后比较函数值                                                        |
| 二阶 Taylor（多元） | $f(\mathbf a+\mathbf h)\approx f(\mathbf a)+\nabla f(\mathbf a)\cdot\mathbf h+\frac12\mathbf h^TH(\mathbf a)\mathbf h$ |
| 雅可比矩阵         | 向量值函数 $\mathbf F$ 的一阶偏导矩阵 $J_{ij}=\partial F_i/\partial x_j$；坐标变换的面积 / 体积伸缩因子为 $\lvert\det J\rvert$                    |
| 常见错误          | 只解一阶条件就判极值；方向导数用未单位化的向量；把"偏导存在"当"可微"                                                                                   |

## 7. 几何应用与多元积分

| 结论 | 公式 / 方法 |
| --- | --- |
| 平面面积 | $A=\int_a^b[\text{上曲线}-\text{下曲线}]\,dx$；交点由联立方程解出，上限 > 下限，必要时取绝对值 |
| 两点距离 | $d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$；先求全部交点再代入 |
| 弧长（显函数） | $L=\int_a^b\sqrt{1+(y')^2}\,dx$，别忘根号 |
| 弧长微元 | $ds=\sqrt{dx^2+dy^2}=\sqrt{1+(y')^2}\,dx$ |
| 弧长（参数式） | $L=\int_a^b\sqrt{(x'(t))^2+(y'(t))^2}\,dt$ |
| 旋转曲面面积 | 绕 $x$ 轴：$S=2\pi\int\lvert y\rvert\,ds$；绕 $y$ 轴：$S=2\pi\int\lvert x\rvert\,ds$（半径 = 到旋转轴的距离） |
| 旋转体体积 | 截面法 $V=\int A(z)\,dz$，$A=\pi r^2$；柱坐标 $dV=r\,dr\,d\theta\,dz$，勿漏 Jacobian $r$ |
| 常用化简 | $1+\tan^2x=\sec^2x$，故 $\sqrt{1+(y')^2}$ 常化为 $\sec x$ |
| 柱坐标 | $(r,\theta,z)$：$x=r\cos\theta$、$y=r\sin\theta$、$r=\sqrt{x^2+y^2}$、$\theta=\operatorname{atan2}(y,x)$；$r\geq0$，$0\leq\theta<2\pi$ |
| 柱坐标曲面 | $r=c\Rightarrow x^2+y^2=c^2$ 圆柱面；$\theta=c$ 过 $z$ 轴的竖直半平面；$z=c$ 水平平面；$r\leq c$ 为实心圆柱 |
| 球坐标 | $(\rho,\theta,\varphi)$：$x=\rho\sin\varphi\cos\theta$、$y=\rho\sin\varphi\sin\theta$、$z=\rho\cos\varphi$；$\rho=c$ 为球面 |
| ※ 圆盘 / 垫片法 | 绕 $x$ 轴：$V=\pi\int_a^b\left[R(x)^2-r(x)^2\right]dx$ |
| ※ 壳层法 | 绕 $y$ 轴：$V=2\pi\int_a^b x\,f(x)\,dx$（旋转半径取 $x$） |
| ※ 曲面面积（二元） | $z=f(x,y)$ 在区域 $D$ 上：$S=\iint_D\sqrt{1+f_x^2+f_y^2}\,dA$ |
| ※ 二重积分（直角） | $\iint_D f\,dA=\int_a^b\int_{g_1(x)}^{g_2(x)}f(x,y)\,dy\,dx$；可交换积分次序但需重画区域 |
| ※ 二重积分（极坐标） | $x=r\cos\theta,\ y=r\sin\theta$，$dA=r\,dr\,d\theta$；适合圆域与被积函数含 $x^2+y^2$ |
| ※ 三重积分 | 柱坐标 $dV=r\,dr\,d\theta\,dz$；球坐标 $dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$；$\iiint_E 1\,dV$ 即体积 |
| ※ 一般变量替换 | $dx\,dy=\left\lvert\det\dfrac{\partial(x,y)}{\partial(u,v)}\right\rvert du\,dv$；$dx\,dy\,dz=\lvert\det J\rvert\,du\,dv\,dw$ |
| ※ 面积 / 质心 / 平均值 | 面积 $=\iint_D 1\,dA$；质心 $\bar x=\frac{\iint_D x\,dA}{\iint_D 1\,dA}$；区域平均值 $=\frac{\iint_D f\,dA}{\text{Area}(D)}$ |
| ※ 格林公式 | $\oint_C P\,dx+Q\,dy=\iint_D\left(\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}\right)dA$；保守场沿闭曲线积分为 0 |
| 常见错误 | 用直角坐标硬凑边界、忘记 Jacobian；只算一个交点；弧长忘记开根号；积分上下限写反 |

## 8. 常微分方程基础（※ 整节为补充）

| 类型 | 通解 / 结论 |
| --- | --- |
| 可分离变量 | $\dfrac{dy}{dx}=g(x)h(y)\Rightarrow\int\dfrac{dy}{h(y)}=\int g(x)\,dx+C$ |
| 一阶线性 | $y'+p(x)y=q(x)$ 的通解 $y=e^{-\int p\,dx}\left(\int q(x)e^{\int p\,dx}dx+C\right)$ |
| 二阶常系数齐次 | $ay''+by'+cy=0$：特征方程 $ar^2+br+c=0$；$\Delta>0$ 两实根 $r_{1,2}$ ⇒ $C_1e^{r_1x}+C_2e^{r_2x}$；$\Delta=0$ ⇒ $(C_1+C_2x)e^{rx}$；$\Delta<0$（$r=\alpha\pm i\beta$）⇒ $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |
| 初值条件 | $n$ 阶方程需 $n$ 个初始条件确定全部任意常数 |
| ※ 指数增长 / 衰减 | $y'=\lambda y$ 的解为 $y=Ce^{\lambda x}$；$\lambda<0$ 衰减、$\lambda>0$ 增长 |

## 9. 三角公式与特殊角

| 结论 | 公式 |
| --- | --- |
| 基本关系 | $\sin^2\theta+\cos^2\theta=1$；$\tan\theta=\dfrac{\sin\theta}{\cos\theta}$；$1+\tan^2\theta=\sec^2\theta$；$1+\cot^2\theta=\csc^2\theta$ |
| ※ 和角公式 | $\sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta$；$\cos(\alpha\pm\beta)=\cos\alpha\cos\beta\mp\sin\alpha\sin\beta$；$\tan(\alpha\pm\beta)=\dfrac{\tan\alpha\pm\tan\beta}{1\mp\tan\alpha\tan\beta}$ |
| 正弦二倍角 | $\sin2\theta=2\sin\theta\cos\theta$ |
| 余弦二倍角 | $\cos2\theta=\cos^2\theta-\sin^2\theta=1-2\sin^2\theta=2\cos^2\theta-1$ |
| 正切二倍角 | $\tan2\theta=\dfrac{2\tan\theta}{1-\tan^2\theta}$ |
| ※ 降幂 / 半角 | $\sin^2\theta=\dfrac{1-\cos2\theta}{2}$、$\cos^2\theta=\dfrac{1+\cos2\theta}{2}$；$\sin\frac\theta2=\pm\sqrt{\frac{1-\cos\theta}{2}}$、$\cos\frac\theta2=\pm\sqrt{\frac{1+\cos\theta}{2}}$ |
| ※ 象限符号表 | 第一象限 $\sin+,\cos+,\tan+$；第二象限 $\sin+,\cos-,\tan-$；第三象限 $\sin-,\cos-,\tan+$；第四象限 $\sin-,\cos+,\tan-$ |
| 符号判断 | 由 $\sin$ 求 $\cos$ 必须带 $\pm$ 并据象限定号；一全正、二仅 $\sin$、三仅 $\tan$、四仅 $\cos$ |
| ※ 特殊角表 | $\theta$ / $\sin\theta$ / $\cos\theta$ / $\tan\theta$：$0$ / $0$ / $1$ / $0$；$\pi/6$ / $1/2$ / $\sqrt3/2$ / $\sqrt3/3$；$\pi/4$ / $\sqrt2/2$ / $\sqrt2/2$ / $1$；$\pi/3$ / $\sqrt3/2$ / $1/2$ / $\sqrt3$；$\pi/2$ / $1$ / $0$ / 不存在 |
| 常用值 | $\sin2\pi=0$、$\cos2\pi=1$、$\ln1=0$、$e^0=1$ |
| 常见错误 | 已知 $\sin\theta>0$ 就断定 $\cos\theta>0$；已知一个三角函数值就唯一确定另一个；半角公式漏 $\pm$ |

## 11. 高频易错点速查

| 陷阱 | 正确结论 |
| --- | --- |
| $\int\ln x\,dx=x\ln x+C$ | 分部积分后还有 $-\int 1\,dx$，正确为 $x\ln x-x+C$ |
| $\int\frac{dx}{\sqrt{x^2+a^2}}$ 记成 arctan | 正确为 $\ln\lvert x+\sqrt{x^2+a^2}\rvert+C$（arctan 对应 $\frac{1}{x^2+a^2}$） |
| 求面积积分限写反 / 忘绝对值 | 上限 > 下限，被积函数取"上 − 下"，必要时分段取绝对值 |
| 弧长直接积分 $\ln(\cos x)$ | 弧长是 $\int\sqrt{1+(y')^2}\,dx$，且 $y'=-\tan x\Rightarrow\sqrt{1+(y')^2}=\sec x$ |
| 反常积分照搬 $\frac12$ | $\int_{-\infty}^0 e^{-2x}dx$ 发散；先判敛散再算值 |
| $0/0$ 直接选 "不存在" / "undefined" | 用洛必达或 Taylor；导数定义本身就是 $0/0$ 型 |
| 分段函数只算右极限 | 左右极限分别算，不等则总体极限不存在 |
| 值域只写端点值 | 闭区间连续函数还要检查区间内的顶点 / 临界点 |
| 偏导算一次就停 | 混合二阶偏导需逐层继续求导，注意符号 |
| 多元极限用几条路径相同就判存在 | 路径相同不能证明存在，须用夹逼或定义 |
| 忘记 Jacobian | 柱坐标体积元是 $r\,dr\,d\theta\,dz$，球坐标是 $\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$，极坐标面积元是 $r\,dr\,d\theta$ |
| ※ 换元后忘记换积分限 | 定积分换元必须同步替换上下限，或回代原变量后再代限 |
| ※ 洛必达用于 $0\cdot\infty$、$1^\infty$ 等 | 必须先化为 $0/0$ 或 $\infty/\infty$；幂指函数取对数 |
| ※ $\int\frac{dx}{x^2+a^2}$ 与 $\int\frac{dx}{\sqrt{a^2-x^2}}$ 记混 | 前者是 $\frac1a\arctan\frac xa$，后者是 $\arcsin\frac xa$ |
| ※ 区间内含奇点仍直接套牛顿-莱布尼茨 | 拆成两段反常积分分别判敛，任一发散则整体发散 |
| ※ 解出 $f_x=f_y=0$ 就断言极值 | 还需 Hessian 判别 $D=f_{xx}f_{yy}-f_{xy}^2$；$D<0$ 是鞍点 |
| ※ 方向导数用任意方向向量 | 必须先把方向向量单位化 |
| ※ 级数项趋于 0 就判收敛 | $a_n\to0$ 只是必要条件；调和级数即反例 |
| ※ 把 $\sum a_n$ 条件收敛当绝对收敛 | 条件收敛级数不能随意重排，重排可能改变和 |
| ※ 多元函数偏导存在就当可微 | 偏导连续才是可微的充分条件；偏导存在不保证连续 |
